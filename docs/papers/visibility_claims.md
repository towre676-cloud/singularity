# Claim-to-evidence matrix for the companion article

This matrix audits `docs/papers/visibility.md` for roadmap push P35. Audit date: 18 October 2026. It has one row per substantive claim of the revised article. Each row gives the claim, its status category, the evidence and any scope caveat. A second table lists statements of the 17 October draft that were flagged and how the revision handled them.

Status categories:

- **Lit**: established literature, cited by a key present in `docs/references.bib`.
- **Proved (SNG-…)**: proved project result. The human-readable proof is in the monograph chapter that declares the identifier; `results/theorem_index.json` lists each declaration and its location.
- **Finite**: exact finite computation over a declared population. It is reproducible by the stated command and replayed by independent enumerators where noted.
- **Lean**: kernel-checked Lean theorem. Names are exact; the package is `formal/` (Lean 4.12.0 core, no Mathlib, no project axioms). The audit file is `formal/AxiomAudit.lean`.
- **Open**: conjecture, open question or explicitly unclaimed statement.

The P33 Lean statements were built locally; see `formal/README.md` for the build and audit. The clean-environment CI build including `Certificates.lean` passed (run 42, commit d7336f8), and P33 is `complete` in `handoff/push_status.json`, as are P07 and P08.
