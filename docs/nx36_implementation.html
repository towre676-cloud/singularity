1 NX36: states, experiments, evidence and limits

1.1 What this companion establishes

The NX36 programme develops a single question across graph interfaces, dynamical systems, arithmetic populations and measured application pilots: which differences can a declared experiment language reveal, at what cost, and with what uncertainty? This implementation companion records the contracts that make that question decidable in bounded cases. It accompanies the graph monograph and the independent frontier companion. It does not replace their definitions or turn their remaining reconstruction questions into solved problems.

An experiment has a population, an intervention, an observation and a cost. Each part is needed. A rank calculation without an uncertainty set does not certify reliable identification. A panel optimum without its candidate catalogue does not certify optimality over every legal physical experiment. A finite coefficient prefix without a generation theorem does not certify equality of infinite series. The modules below return explicit finite answers, witnesses, or resource-bound refusals under recorded assumptions.

Let the original candidate population be Ω\Omega, the target be τ:Ω→𝒯\tau:\Omega\to\mathcal T, and the possible outputs of experiment ee on candidate ω\omega be Ye(ω)Y_e(\omega). For independently reset scalar experiments a panel PP identifies the target exactly when

∀ω,ω′∈Ω,τ(ω)≠τ(ω′)⇒∃e∈P:Ye(ω)∩Ye(ω′)=⌀. \forall\omega,\omega'\in\Omega,\quad \tau(\omega)\ne\tau(\omega') \Longrightarrow \exists e\in P:\ Y_e(\omega)\cap Y_e(\omega')=\varnothing.

This statement concerns closed output sets: touching endpoints are ambiguous. When the same nuisance variable persists across observations, the correct object is the joint attainable set YP(ω)Y_P(\omega); scalar interval projections can discard information. When interventions share physical history, the state and nuisance variables must persist through the whole word. The implementation keeps these models distinct.

1.4 What changed in practice

The thermal work expands from a six-candidate example into several distinct experimental models. The original 112-test pool remains available for fair comparison. A separate 79-member fault population keeps all masks with at most two faults on twelve explicitly selected plate bonds. Some finite catalogues identify fewer response classes than original masks; the receipts retain those blind pairs. A maximal observable quotient is useful, but it does not identify faults that the experiment language cannot distinguish.

Persistent-error geometry can certify a joint separation that every independent scalar projection misses. Adaptive policies can sometimes save experiments, but the retained original thermal pool gives an honest case where adaptive and static costs coincide. Shared-history experiments use a different contract and can exploit information collected before a reset erases it. Their savings are compared only with a static language using the same controls, sensors, initial-state assumptions and noise model.

Low-rank fault transport separates a reusable nominal calculation from each fault correction. If a blocked bond has incidence vector bb, then its discrete transition has the form

Aγ=A0+γbb𝖳, A_\gamma=A_0+\gamma bb^\mathsf T,

with the sign determined by removing conductance from the nominal conservative update. The implementation checks this sign against independent neighbour-flux evolution. Resolvent or coefficient Woodbury identities operate on small fault-index matrices, while the full state and sensor dimensions remain in the source binding. A rank-one algebraic identity does not automatically transport a nominal uncertainty certificate to a damaged model; each claimed bound must be valid for the actual fault/sensor/protocol combination.

The graph frontiers gain stronger tools without assuming their general conjectures. Exact integer quotients expose congruence constraints hidden by rational row spaces. A rationally realizable state need not have an integer preimage. Parameter receipts distinguish rank at q=1/2q=1/2 from rank on an interval. Structural graph searches report their constructor bounds and can establish exclusions for promised families; failure to find a pair in a finite search does not rule out a larger realization. The effective-prefix work supplies genuine infinite conclusions in restricted sectors by proving the rule that advances coefficients.

The period work follows the same discipline. A differential observable is generated by covariant derivatives of a row, and a reduced connection must satisfy an exact moving-basis identity. If BB is a row reduction of the original system y′=Ayy'=Ay, then

B′+BA=DB,r=ρB B'+BA=DB,\qquad r=\rho B

proves that z=Byz=By obeys z′=Dzz'=Dz and preserves target ry=ρzry=\rho z. On an overlap B̃=GB\widetilde B=GB, the reduced connections must satisfy

D̃=(G′+GD)G−1. \widetilde D=(G'+GD)G^{-1}.

Local gauge identities alone do not prove loop holonomy. The monodromy receipts therefore bind source equations, paths, normalization and independent validated continuation. Numerical proximity to an integer matrix does not authorize exact integer recovery without a lattice premise.

1.6 Consequences for the wider programme

The project now has a reusable path from a mathematical observation to a declared experiment, a costed design, an uncertainty-aware distinction and a portable certificate. This makes the earlier graph interfaces operational and lets the same questions be asked of thermal faults, arithmetic states and period targets. It also makes negative results actionable: a blind direction says which information the current language lacks, and a poorly conditioned decoder says which experiment needs a stronger signal.

Three broad graph research questions remain separate from completing this implementation programme: efficient reconstruction beyond the graph classes already proved, completeness or a full-series collision for fixed pinning, and realization of surviving symmetric-interface ambiguities. These require new mathematics. The modules and receipts in this companion improve the tools, constraints and experimental evidence available for those questions.

2 Candidate-specific uncertainty boxes for finite experiment panels (NX01)

This note covers track NX01 of the NX36 expansion. The existing thermal pilot (THERMAL_DIAGNOSTICS.md) computes an uncertainty radius for every experiment and candidate. It then deliberately replaces those radii by one common envelope per experiment before calling the panel optimizer (PANELS.md). The question here is whether keeping the individual radii changes the cheapest guaranteed diagnosis. It adds no new physical calibration, fault population, correlated-error model or global robustness claim.

Short answer: on the unchanged 112-protocol, six-candidate 12 by 12 plate pool, the cheapest guaranteed panel still costs 20 units, and the per-candidate radii do not change a single coverage decision under the primary contract. On a declared 12-protocol sub-pool of the 4 by 4 plate, the common envelope cannot identify the candidates at any cost, but the per-candidate boxes can, at cost 19. Both statements are exact finite computations, checked by independent oracles.

Implementation: candidate_boxes.py (production), candidate_box_oracles.py (independent oracles), test_candidate_boxes.py, receipt candidate_box_thermal.py with retained result candidate_box_thermal.json.

2.1 1. Objects and contract

A pool has experiments e=1,…,Ee=1,\dots,E with exact nonnegative rational costs κe\kappa_e, and original candidates c=1,…,Kc=1,\dots,K, K≥2K\ge2, with distinct identifiers. Each candidate has a target label T(c)T(c); by default every candidate is its own target. For each experiment and candidate there is an exact central reading recr_{ec} and a nonnegative rational radius ρec\rho_{ec}. The radius matrix is indexed experiment first, candidate second. Its transpose is a different contract, even when E=KE=K makes the shapes agree.

Uncertainty contract. Running experiment ee when the truth is cc yields one reading in the closed interval

Iec=[rec−ρec,rec+ρec]. I_{ec}=[\,r_{ec}-\rho_{ec},\;r_{ec}+\rho_{ec}\,].

Experiments are independently reset, so the readings of a panel PP range over the product box Yc(P)=∏e∈PIecY_c(P)=\prod_{e\in P}I_{ec}. The contract asserts that every reading actually produced lies in this box. For the necessity half of Theorem 3, every point of the box must also be a possible reading. That holds for the thermal pilot (Section 6) but not for every radius that is merely an upper bound.

Required pairs. R={{a,b}:a<b,T(a)≠T(b)}R=\{\{a,b\}: a<b,\ T(a)\ne T(b)\}. Pairs with a shared target need not be separated. Their candidates are still kept as distinct original hypotheses, with distinct identifiers.

Plain-language summary. Every candidate has its own “error bar” in every experiment. A set of experiments is good when, whatever the true candidate and whatever the errors within their bars, the readings rule out every candidate with a different target.

2.2 2. Geometry

Lemma 1 (closed intervals). For ρa,ρb≥0\rho_a,\rho_b\ge0, the intervals [ra−ρa,ra+ρa][r_a-\rho_a,r_a+\rho_a] and [rb−ρb,rb+ρb][r_b-\rho_b,r_b+\rho_b] are disjoint if and only if |ra−rb|>ρa+ρb|r_a-r_b|>\rho_a+\rho_b.

Proof. Without loss of generality ra≤rbr_a\le r_b. Two closed intervals on the line are disjoint exactly when the upper end of the left-hand one is strictly below the lower end of the right-hand one. Their order is fixed by their centers when they are disjoint: if ra≤rbr_a\le r_b and the intervals are disjoint, then IaI_a lies to the left. So disjointness means ra+ρa<rb−ρbr_a+\rho_a<r_b-\rho_b, that is rb−ra>ρa+ρbr_b-r_a>\rho_a+\rho_b. Conversely, if rb−ra≤ρa+ρbr_b-r_a\le\rho_a+\rho_b, the point max(ra−ρa,rb−ρb)\max(r_a-\rho_a,r_b-\rho_b) is at most min(ra+ρa,rb+ρb)\min(r_a+\rho_a,r_b+\rho_b), so the intersection is nonempty. ▫\square

Write the raw margin Δeab=|rea−reb|−ρea−ρeb\Delta_{eab}=|r_{ea}-r_{eb}|-\rho_{ea}-\rho_{eb}. Experiment ee separates {a,b}\{a,b\} iff Δeab>0\Delta_{eab}>0. The cases this rules on are exactly the ones tested:

  • Touching endpoints (Δ=0\Delta=0). The shared endpoint is a possible reading under both candidates, so this is not separation.
  • Zero radii. ρ=0\rho=0 is a degenerate closed interval. Two exact readings separate iff they differ. A zero radius against a positive one separates iff the exact point lies strictly outside the other interval. The common backend requires strictly positive noisy margins; this module does not.
  • Identical centers (rea=rebr_{ea}=r_{eb}). Then Δ≤0\Delta\le0 whatever the radii, so the pair is never separated by ee. The witness reading is the common center.

Lemma 2 (boxes). Ya(P)∩Yb(P)=⌀Y_a(P)\cap Y_b(P)=\varnothing iff some e∈Pe\in P has Δeab>0\Delta_{eab}>0.

Proof. A product of sets is empty-intersecting with another product exactly when some coordinate pair is disjoint. If every coordinate pair meets, choosing one common point in each coordinate gives a common point of the boxes. Apply Lemma 1 coordinatewise. ▫\square

For the empty panel the box is the one-point product, so no pair is separated. Hence the empty panel is feasible exactly when R=⌀R=\varnothing.

2.3 3. Decoder and identification

The decoder for panel PP and observation vector y∈ℚPy\in\mathbb Q^P returns

DP(y)={c:|ye−rec|≤ρecfor all e∈P}={c:y∈Yc(P)}. D_P(y)=\{c:\ |y_e-r_{ec}|\le\rho_{ec}\ \text{for all }e\in P\}=\{c: y\in Y_c(P)\}.

Its target output is T(DP(y))T(D_P(y)).

Theorem 3 (cover iff guaranteed target identification). Suppose every point of every box is a possible observation. Then the following are equivalent:

  1. every required pair is separated by some member of PP;
  2. for every candidate cc and every possible observation y∈Yc(P)y\in Y_c(P), T(DP(y))={T(c)}T(D_P(y))=\{T(c)\}.

Proof. (1)⇒(2). The truth cc is always in DP(y)D_P(y), since y∈Yc(P)y\in Y_c(P). If d∈DP(y)d\in D_P(y) with T(d)≠T(c)T(d)\ne T(c), then y∈Yc(P)∩Yd(P)y\in Y_c(P)\cap Y_d(P). By Lemma 2 this contradicts (1).

(2)⇒(1). Suppose {a,b}∈R\{a,b\}\in R is unseparated. In each coordinate, the intersection Iea∩Ieb=[max(lower ends),min(upper ends)]I_{ea}\cap I_{eb}=[\max(\text{lower ends}),\min(\text{upper ends})] is nonempty by Lemma 1. Let yey_e be its midpoint. Then y∈Ya(P)y\in Y_a(P), so it is possible under truth aa, and DP(y)⊇{a,b}D_P(y)\supseteq\{a,b\} has two targets. ▫\square

candidate_box_ambiguity returns exactly this witness (a,b,y)(a,b,y) for the first unseparated required pair. The direction (1)⇒(2) needs only the enclosure half of the contract. If radii are only upper bounds, a covering panel still certifies identification, but an ambiguity witness might not be physically attainable. Sharper radii without a proof change the problem; they are not a refinement.

An empty decoder output, which is possible when an observation lies outside every box, signals that the model contract failed. It does not identify an unmodelled fault.

2.4 4. Comparison with the common envelope

Let εe=maxcρec\varepsilon_e=\max_c\rho_{ec} (common_envelope).

Proposition 4 (monotonicity). If |rea−reb|>2εe|r_{ea}-r_{eb}|>2\varepsilon_e then Δeab>0\Delta_{eab}>0. Hence every common-envelope covering panel is a heterogeneous covering panel, and the heterogeneous optimum costs at most the common-envelope optimum. 2.5 5. Exact optimization

With Me={p∈R:e separates p}M_e=\{p\in R: e\text{ separates }p\}, a panel covers iff ⋃e∈PMe=R\bigcup_{e\in P}M_e=R (Lemma 2). Minimum-cost selection is therefore weighted set cover on required pairs. This problem is NP-hard in general.

Production solver (minimum_candidate_box_panel). This is a private branch-and-bound kernel over validated masks; the masks are always produced from readings and radii inside the module. It follows the design proved in PANELS.md:

  • Dominance reduction. Experiment ff dominates ee when Mf⊇MeM_f\supseteq M_e and κf≤κe\kappa_f\le\kappa_e, with strict improvement or an index tie-break. Removing empty and dominated experiments keeps an optimum, because replacing a dominated member by its dominator never increases cost or loses coverage. The tie-break makes the relation a strict partial order, so a kept dominator exists.
  • Branching. Pick an uncovered pair pp with fewest admissible coverers e1,…,eme_1,\dots,e_m, ordered by cost. Branch ii includes eie_i and excludes e1,…,ei−1e_1,\dots,e_{i-1}. Every cover contains some coverer of pp, and the branch indexed by its first coverer in this order is unique, so the branches partition the covers.
  • Bounds. Pairs are taken greedily so that no admissible experiment covers two of them. Summing their cheapest admissible coverers gives the packing bound, a valid lower bound because those coverers are distinct experiments. Without packing, the bound is the maximum cheapest coverer.
  • Termination with zero costs. Every branch removes at least one experiment from the admissible set, so the tree is finite whatever the costs. A pool of many zero-cost experiments separating nothing is pruned by the reduction and never searched as repeated words.
  • Budget. max_nodes=10**6 by default. Exceeding it returns inconclusive with the greedy-or-better incumbent as an upper bound and the root packing bound as a proved lower bound. An exhausted budget never produces infeasible. infeasible is returned only when some required pair has no separating experiment in the whole pool, and every such pair is listed.

Independent oracles (candidate_box_oracles). This module never imports the production module. It recomputes separation from interval endpoints, max(lower)≤min(upper)\max(\text{lower})\le\min(\text{upper}), instead of the production margin formula:

  • exhaustive_box_panel scans every subset (bounded by max_subsets, default 2162^{16}) and tests product-box intersection directly.
  • cost_bounded_box_panel scans every subset of total cost at most a declared bound. If none separates, no panel of cost at most the bound exists. With positive costs this is affordable on large pools when the bound is small.
  • cover_state_dijkstra is Dijkstra’s algorithm on reached sets of separated pairs, with one edge per experiment. Repeating an experiment never enlarges a covered set, so with nonnegative costs a cheapest path uses distinct experiments and equals the cheapest cover. For K=6K=6 there are at most 2152^{15} states.

The tests compare all three oracles with the solver, under all four packing and reduction settings, on 300 seeded tiny rational pools. These pools have up to 7 experiments and up to 4 candidates, with mixed zero and positive radii, half-integer readings, zero costs and occasional shared targets. Dedicated tests cover dominated experiments, zero-cost combinations, budget exhaustion and the common-backend comparison. A greedy result is never reported as optimal: optimality is claimed only from completed search, and that search is checked by the oracles.

3.1 Contract and data orientation

Yc=μc+Gc[−1,1]mc. Y_c=\mu_c+G_c[-1,1]^{m_c}.

3.2 Support and completeness theorem

SNG-NX02-01. For a rational contrast w,

hc(w)=maxz∈[−1,1]mcwTGcz=∑j|(GcTw)j|. h_c(w)=\max_{z\in[-1,1]^{m_c}}w^TG_cz =\sum_j|(G_c^Tw)_j|.

|wT(μa−μb)|>ha(w)+hb(w) |w^T(\mu_a-\mu_b)|>h_a(w)+h_b(w)

certifies disjoint sets. The strict inequality matters: equality can leave a common boundary point and is rejected by the checker.

joint_pair_certificate solves the exact overlap problem, rather than merely searching a list of sufficient contrasts. Set A=[G_a,-G_b] and b=mu_b-mu_a. The solver converts Az=b and -1<=z<=1 into rational inequalities. It repeatedly eliminates the last variable by pairing a positive-coefficient inequality with a negative-coefficient inequality. A zero-coefficient inequality is retained. If one side has no bound, elimination imposes no extra condition from that side. These are exactly the conditions that the lower bounds on the eliminated variable do not exceed its upper bounds. Induction proves equivalence of the projected feasible set and the eliminated system.

Every generated row carries nonnegative multipliers on the original rows. An impossible constant row therefore supplies an exact Farkas certificate. For a feasible final system, back substitution selects zero where possible and otherwise an available rational endpoint. The returned point is replayed against every original inequality before being reported.

To obtain a separating contrast from an infeasibility certificate, let lambda_i be the multiplier on the positive equality row minus that on its negative copy. The nonnegative box-bound multipliers have total at least ||A^T lambda||_1, because their signed difference cancels A^T lambda. The negative constant row implies

λTb+∑bound multipliers<0. \lambda^Tb+\textstyle\sum\text{bound multipliers}<0.

Thus |lambda^T b|>||A^T lambda||_1. Splitting A into its two candidate blocks gives exactly the support inequality above. This proves that, whenever the bounded exact elimination finishes, the engine returns either a primal overlap witness or a strict rational separating contrast. It does not depend on a floating optimization status or a generic convex-separation assertion.

4.1 Exact populations and prefix completion counts

For ordered distinct bond IDs e_1,…,e_m, the original population is

Ω={θ∈{0,1}m:Rθ≤b}. \Omega=\{\theta\in\{0,1\}^m:R\theta\le b\}.

FaultPopulation accepts integer inequalities, an optional cardinality cap, an optional source-model digest and a completion-state budget. General signed integer rows are allowed, so coupling constraints such as theta_1+theta_2<=1 and theta_3+theta_4<=theta_2 are not reduced to independent cardinality limits. For a prefix p of length t, subtract its contribution from each original constraint. The memoized state consists of t and this residual right-hand side. The smallest possible remaining contribution of row r is the sum of its negative coefficients. If that lower bound exceeds the residual bound, the prefix has no completion. At t=m every surviving state is a feasible original mask. Otherwise

C(p)=C(p0)+C(p1). C(p)=C(p0)+C(p1).

SNG-NX03-01. The completion recurrence, with the stated rejection rule, counts every original feasible Boolean mask exactly once. Lexicographic rank adds C(p0) when the next bit is one. Unrank compares the requested index with C(p0), follows the zero branch when smaller and subtracts that count before taking the one branch otherwise. Induction on remaining length proves that these maps are inverse. Enumeration is implemented by unranking all integer indices; its own mask-count budget is separate from the completion-state budget. 5.1 Physical coordinates and admissibility

5.2 Symbolic maps and interval enclosures

Polynomial stores a sparse map from nonnegative multiexponents to rational coefficients. Addition combines equal monomials and multiplication convolves them. panel_parameter_map propagates the source stencil symbolically, with separately reset zero initial states for every requested word. Every coordinate of a finite-horizon response is therefore represented exactly as a polynomial in the four parameters. The default horizon is four and the coefficient budget is 100,000 terms across an evolved state. Exceeding either is a refusal to compile a larger problem, not a physical conclusion.

For a closed rational box, each univariate monomial factor is bounded exactly at its endpoints, also including zero for an even power across a sign change. Interval multiplication encloses each multivariate monomial, and summing these intervals encloses the whole polynomial. The resulting enclosure can be wider than the actual image because separate monomials can share variables. It is nevertheless a valid deterministic outer bound. This distinction is retained throughout the separation proof.

An independent two-step expansion verifies all symbolic coefficients. If the first input is two, the second zero, the source starts at zero and b is the unscaled heater, then

x2=2g{(1−λ)b−kLb+kαvvTb}. x_2=2g\{(1-\lambda)b-kLb+k\alpha vv^Tb\}.

2g{(1−λ)cTb−k∑ab∈E(ca−cb)(ba−bb)+kα(cu−cv)(bu−bv)}. 2g\{(1-\lambda)c^Tb-k\sum_{ab\in E}(c_a-c_b)(b_a-b_b) +k\alpha(c_u-c_v)(b_u-b_v)\}.

5.3 Full-domain contrast certificates

ParametricFaultFamily specifies a polynomial observation vector and compact box. Left and right hypotheses have independent parameter assignments. 2∑i|wi|ϵi. 2\sum_i|w_i|\epsilon_i.

max(la−ub,lb−ua)−2∑i|wi|ϵi \max(l_a-u_b,l_b-u_a)-2\sum_i|w_i|\epsilon_i

Strict margins cover those boundaries as well. verify_family_certificate reconstructs every split and replays every leaf enclosure and gap. A full separated result requires every leaf to pass.

9 NX08: stable target recovery

This note covers the mathematics behind src/singularity/target_recovery.py. The tests are in tests/test_target_recovery.py, and the retained receipt is results/target_recovery.json, which scripts/target_recovery.py --check replays. The setting is finite-dimensional, linear, rational and deterministic. Noise lies in a declared ellipsoid. The note makes no statistical, calibrated-physical or nonlinear-global claim.

The question is this. When sensors determine a requested target exactly in the absence of noise, how much can bounded measurement error move the recovered target? Two sensor layouts of equal rank can answer this very differently, so rank alone cannot rank designs.

9.1 1. Objects and conventions

  • State. A state is a vector x in Q^d. The admissible states are x = x_c + Qz, where Q is a rational d×k matrix of full column rank and z is unrestricted. A zero-dimensional admissible set (k = 0) is allowed.
  • Observations and target. The observations are y = Hx + η, with H an m×d matrix. The target is t = Gx, with G a p×d matrix. The known centres Hx_c and Gx_c are subtracted. Write H₀ = HQ and G₀ = GQ.
  • Noise. η satisfies η^T R^{-1} η ≤ ε². Here R is the positive-definite ellipsoid shape matrix, with default I, which is the convention in INTERCHANGE_CONTRACT.md. Write W = R^{-1} and ‖η‖²_W = η^T W η.
  • Target error. Target error is ‖e‖²_P = e^T P e for a positive-definite P, with default I.
  • Forms. A = H₀^T W H₀ and B = G₀^T P G₀ are positive semidefinite (PSD) k×k matrices. For α ≥ 0, S(α) = αA − B.

Definition. The squared target amplification is

κ² = min{α ≥ 0 : S(α) ≽\succeq 0}, and κ² = +∞ when no such α exists.

The set of admissible α is closed and upward-closed, so the minimum exists when the set is nonempty. When some z has H₀z ≠ 0, κ² equals sup ‖G₀z‖²_P / ‖H₀z‖²_W over such z. When H₀ = 0 and G₀ = 0, κ² = 0. This is the convention for “no admissible variation of the target”, and it avoids a division by zero.

Invariance. κ* depends only on three things: the admissible subspace image(Q), the target metric P and the noise metric R. Replacing Q by QT for an invertible T maps z to T^{-1}z and leaves every ratio unchanged. An invertible state coordinate change x’ = Tx sends H to HT^{-1}, G to GT^{-1} and Q to TQ, so H₀ and G₀ do not change. No state norm appears anywhere. Changing observation or target units does change R or P, and therefore κ*. This is why units and metrics are stored in every receipt. The test test_basis_invariance_and_whitening checks basis invariance. It also checks that R = diag(4, 9, 1) is identical to dividing the observation rows by 2 and 3.

9.2 2. Exact theorems

Theorem 1 (kernel criterion). The following are equivalent: (a) κ* < ∞; (b) ker H₀ ⊆ ker G₀; (c) G₀ = LH₀ for some p×m matrix L.

Proof.

  • (b)⇔(c) is the row-space statement: every row of G₀ is a combination of rows of H₀ exactly when every vector annihilated by H₀ is annihilated by G₀.
  • (a)⇒(b): suppose some n has H₀n = 0 and G₀n ≠ 0. Then n^T S(α) n = −‖G₀n‖²_P < 0 for every α, so no α works.
  • (b)⇒(a): let Z be a basis of row(H₀), the orthogonal complement of ker H₀ = ker A. Write any z as Zw + n with n ∈ ker H₀ ⊆ ker G₀. Then z^T A z = w^T A_r w and z^T B z = w^T B_r w, where A_r = Z^T A Z is positive definite and B_r = Z^T B Z.
  • S(α) ≽\succeq 0 exactly when α ≥ λ_max(A_r^{-1} B_r), so κ*² is finite. ▫\square

If the kernel condition fails, the code returns unobservable with an exact hidden-target witness: a primitive integer z with H₀z = 0 and G₀z ≠ 0. In words, the admissible states x_c and x_c + Qz produce identical noiseless readings but different targets.

Theorem 2 (no decoder beats εκ*). Let D be any map from observations to target estimates, linear or not. Then sup over admissible x and ‖η‖_W ≤ ε of ‖D(Hx + η) − Gx‖_P is at least ε·κ*. If the kernel condition fails, the error is unbounded.

Proof.

  • Take z with ‖H₀z‖_W ≤ ε.
  • The state x_c + Qz with noise −H₀z and the state x_c − Qz with noise +H₀z both produce the reading Hx_c. Both noises are admissible.
  • Their targets differ by 2G₀z. Whatever D outputs, it is at distance at least ‖G₀z‖_P from one of the two targets.
  • Taking the supremum over z gives εκ*. If z is a hidden-target witness, scaling z makes the gap arbitrarily large while the readings stay identical. ▫\square

adversarial_witness builds exactly these two states and noises, and replays them through a supplied decoder.

Theorem 3 (the minimum-norm decoder attains εκ*). Assume the kernel condition. Let Z be as above, H_Z = H₀Z and

L* = G₀ Z (H_Z^T W H_Z)^{-1} H_Z^T W.

Then LH₀ = G₀, and ‖Lη‖_P ≤ κ*‖η‖_W for every η. The estimate t̂ = Gx_c + L(y − Hx_c) therefore has error at most εκ.

Proof.

  • Decoder identity. For z = Zw + n we have H₀n = 0, so L*H₀z = G₀Z(H_Z^T W H_Z){-1}(H_ZT W H_Z)w = G₀Zw. This equals G₀z because G₀n = 0.
  • Gain bound. Decompose η = H_Z w + η_⊥ with η_⊥ W-orthogonal to image(H₀). Then L*η = G₀Zw, and ‖η‖²_W = ‖H_Z w‖²_W + ‖η_⊥‖²_W ≥ ‖H₀Zw‖²_W.
  • Hence ‖L*η‖_P = ‖G₀Zw‖_P ≤ κ*‖H₀Zw‖_W ≤ κ*‖η‖_W. ▫\square

L* is the rational form of G₀H₀^+ in the whitened geometry. It never forms a floating pseudoinverse.

Arbitrary decoders. Any decoder L with LH₀ = G₀ has gain at least κ², by Theorem 2. It can be strictly worse, because it may amplify noise that lies off the observation image. target_identifiability also returns a row-space decoder, which expresses each target row in the independent rows of H₀. That decoder is valid, but it is not optimal. In the retained two-row example, its exact squared gain is in [13.090169…, 13.090170…], while κ² is in [3.0962912…, 3.0962919…]. A decoder identity therefore never certifies a noise guarantee by itself. certify_decoder_norm certifies β²W − L^T P L ≽\succeq 0 for the chosen L. recover_target refuses a certificate that fails to verify.

Single target row. When p = 1, B_r has rank one, so κ² = g Z A_r^{-1} Z^T g^T · P₁₁ is rational. Any nonzero column of A_r^{-1}B_r is an exact maximizer, and the bracketing routine always returns exact_sharp_constant in this case. With two or more target rows, κ² is generally an algebraic number of degree up to min(rank H₀, p).

9.3 3. Exact PSD certificates with zero pivots

Strict positive-definiteness tests are the wrong tool here. These include DynaComp stability.positive_definite and the LDL inside experiment_design.RationalMetric. Invisible nuisance directions force S(α) to be singular, and S(κ*²) is always singular. psd_certificate(S) performs symmetric elimination in the given order.

  • Positive pivot. It is eliminated, and the Schur complement of a PSD matrix is PSD.
  • Zero pivot. It is accepted only if its whole remaining column is zero. Every 2×2 principal minor s_kk s_ii − s_ik² of a PSD matrix is nonnegative, so a zero diagonal entry forces a zero row. The pivot then contributes D_k = 0 and an identity column of L.
  • Negative pivot, or zero pivot with a nonzero entry s_ik. The routine builds an exact vector v on the remaining coordinates with v^T C v < 0. For a negative pivot, v = e_k. Otherwise, v = te_k + e_i with t = −(|c_ii| + 1)/(2c_ik), which gives −(|c_ii| + 1) + c_ii < 0. The routine then lifts v through the eliminated positive-pivot block by solving S_II z_I = −S_IJ v, so that z^T S z = v^T C v < 0. The lifted vector is re-evaluated exactly before it is returned.

Soundness. The certificate is S = L diag(D) L^T, with L unit lower triangular and D ≥ 0. This implies PSD with no further argument. verify_psd_certificate and the receipt verifier check only this identity. They never rerun the elimination.

Completeness. It follows from the two facts above. Section 8 lists the independent oracles that check it.

9.4 4. Rational brackets for κ*²

bracket_target_amplification(problem, tolerance, max_steps) returns one of four statuses:

  • unobservable, with a hidden witness;
  • exact_sharp_constant, where lower = upper, with an attaining witness and a PSD certificate;
  • bracketed_sharp_constant, where upper − lower ≤ tolerance;
  • resource_limit, a valid bracket that is still wider than the tolerance after max_steps PSD tests.

It never reports infinity as a number. The routine has four parts.

  1. Initial upper bound. It uses trace(A_r^{-1}B_r). Every eigenvalue is nonnegative, so this is at least λ_max. S(trace) is then certified, which must succeed.
  2. Lower witnesses. It evaluates exact ratios of candidate directions: coordinate directions of row(H₀), exact columns of A_r^{-1}B_r, and a few power-iteration directions rounded to small denominators. Rounding only affects which direction is tried. The ratio is always computed exactly, and any exact ratio is a valid lower bound.
  3. Bisection. It tests the simplest rational in the middle third of the bracket. PSD success lowers the upper bound. Failure yields z with z^T S(mid) z < 0, that is, ratio(z) > mid, which raises the lower bound to ratio(z).
  4. Snapping. Let c be the simplest rational in the bracket. If S(c) is PSD and some null vector v of S(c) has v^T A v > 0, then v^T B v = c·v^T A v, so κ*² = c exactly. Both facts are verified exactly. This is how the τ = 3 forecast target closes at exactly 5/2.

9.5 5. Sensor layouts (NX08-B)

A SensorOption has three parts: one or more rows, a positive installation cost, and a positive-definite noise-shape block. A layout stacks the chosen options in index order and uses a block-diagonal R. The noise contract is the joint ellipsoid η^T R^{-1} η ≤ ε² over all installed rows. It is not an independent per-sensor box. A box is a different support-function problem that this module does not compute.

Monotonicity lemma. Adding a sensor adds the PSD term H_s^T R_s^{-1} H_s to A. So S(α) for a superset is at least S(α) for the subset, κ*² cannot increase, and the kernel condition is preserved.

Consequences:

  • The decision “κ*² ≤ κ_max²” is exactly the LDL test of S(κ_max²) for one layout. No bisection is needed.
  • In the pruned search, a node is pruned when its cost already exceeds the incumbent.
  • A node is also pruned when the node plus all remaining options is infeasible. By monotonicity every completion then fails.
  • A feasible node is a leaf, because every extension costs strictly more.

10 Experiment, rank and executable arithmetic selection (NX09)

A computational envelope and a physical observation uncertainty play different roles. The centre produced by an approximate evaluator need not equal the exact full-model reading. Its certified computational radius encloses that difference. Sensor error surrounds the actual physical observation. With all terms in the same output units and at the same chronological sample,

Ie,c,f=r̂e,c,f+[−ρphys−ρcomp,ρphys+ρcomp],ρcomp≤ρsource+ρtransformation+ρreduction+ρexecution. Each summand is nonnegative and is retained individually in source evidence. Triangle inequality proves this composition. 13 Complete constrained protocol populations (NX12)

A physical protocol consists of an original chronological symbol word and a terminal sensor identity. Different words or sensors remain different original experiments even if their readings coincide. The completion compiler compresses counting, not identity or multiplicity.

A deterministic finite automaton supplies states qq, start q0q_0, transition δ\delta and accepting states. Each symbol has a physical scalar amplitude, strictly positive rational elapsed/action cost and nonnegative integer resource increments. A sensor has its own cost and installation requirements. The protocol budget also includes reset cost, a finite horizon and a switch limit. The first symbol does not count as a switch.

13.1 Completion theorem

Scale every rational price by their exact common denominator DD, refusing a declared scale budget if necessary. A completion state is

σ=(q,B,𝐛,h,alast,s,ℓ), \sigma=(q,B,\mathbf b,h,a_{\mathrm{last}},s,\ell),

where BB is remaining scaled cost, 𝐛\mathbf b remaining resources, hh remaining horizon, ss remaining switches and ℓ\ell elapsed length. For each feasible symbol, consume its actual resources and one horizon step. The terminal contribution counts legal installed sensors only when the grammar accepts and the empty/nonempty convention permits termination:

C(σ)=t(σ)+∑a:feasibleC(σ⋅a). C(\sigma)=t(\sigma)+\sum_{a:\text{feasible}}C(\sigma\cdot a).

Induction on hh proves the count. Every word has exactly one DFA path; rejecting duplicate (q,a)(q,a) transitions prevents counting ambiguous derivations as separate words. Missing transitions make words illegal. Strictly positive symbol cost and finite horizon exclude zero-cost cycles. Zero heater amplitude still consumes one positive-cost elapsed step.

Ranking uses a fixed order: legal terminal sensors in input order, followed by symbol branches in alphabet order. Each branch owns a consecutive interval of completion ranks. Descending the unique interval proves rank(unrank(i))=i; summing earlier intervals proves the converse for every legal original protocol. Conditioning on a prefix changes only the completion start state. Conditioning on terminal sensor restricts the terminal term, without deduplicating words.

The number of reachable dynamic states depends on the numeric resource and scaled-cost ranges. Complexity is pseudo-polynomial, not polynomial in arbitrary budget bit length. Explicit materialization checks the exact root count before producing at most the requested number of members. A resource refusal does not imply an empty scientific population.

14 Typed observability: finite type graphs, graph adapters and cheapest witnesses (NX13)

14.1 What this note covers

The existing observation engine (observability.py) works in one state space. Every action there is a square matrix on that space. Some graph operations do not fit that picture. Introducing a terminal, forgetting one, or adding the edge between the two terminals changes what the boundary looks like. A single ambient matrix can hide an illegal composition. Adding the terminal edge twice is the clearest case: the algebra silently computes a multigraph.

This note extends the engine to a finite directed graph of state types. It has three parts:

  1. NX13-A. The typed algebra contract: closure, quotient invariance, per-type minimality and the cheapest-witness property, with proofs.
  2. NX13-B. One finite boundary grammar for graph assembly that genuinely closes at a fixed volume budget. It is checked against height enumeration on the actual assembled graphs.
  3. NX13-C. Portable certificates that replay without the closure computation. Cheapest witnesses are compared with exhaustive legal-path search under a cost bound.

The four categories are kept separate. Sections 2–4 are proved project results about the typed algebra and the grammar’s formulas. Section 5 records exact computations over declared finite populations. Section 7 lists what remains outside scope.

Code: src/singularity/typed_observability.py (algebra and portable format) and src/singularity/typed_contexts.py (graph adapter). Tests: tests/test_typed_observability.py and tests/test_typed_contexts.py. Receipt: scripts/typed_contexts.py and results/typed_contexts.json.

14.3 2. The typed algebra (NX13-A)

14.3.1 Algorithm

typed_closure keeps a priority queue of actual experiments, ordered by cost. It starts with all observations, read with the empty word. It pops the cheapest experiment ee, which starts at type bb. If ρ(e)\rho(e) is independent of the rows already retained at bb, the algorithm retains ee. It then pushes the child (a⋅e)(a\cdot e) for every action aa with t(a)=bt(a)=b. The child’s row is ρ(e)Ma\rho(e)M_a, it starts at s(a)s(a), and its cost is c(e)+cac(e)+c_a. Prepending is correct because the action aa happens before the experiment ee. Dependent rows are discarded and never extended.

The algorithm outputs retained witness rows BbB_b (a rb×dbr_b\times d_b matrix whose rows are actual experiments), and unique coordinates AbA_b and TaT_a with

L=ALBb(L at b),Bt(a)Ma=TaBs(a), L=A_L B_b\ \ (L\text{ at }b),\qquad B_{t(a)}M_a=T_aB_{s(a)},

where TaT_a has shape rt(a)×rs(a)r_{t(a)}\times r_{s(a)}. Neither AA nor TT need be square. The kernel Nb=kerBbN_b=\ker B_b is reported as an exact basis.

14.3.2 Lemma 1 (monotone pops, termination)

Every child costs strictly more than its parent, and children are pushed only when the parent is popped. So the popped costs never decrease. Each retained row raises the rank at its type by one. Hence at most D=∑bdbD=\sum_b d_b rows are retained. Only retained rows have children, so at most 1+D⋅|A|1+D\cdot|A| batches of pushes happen and the algorithm stops.

14.3.3 Theorem 1 (typed closure and cost filtration)

For every legal experiment (w,L)(w,L) starting at bb, the row ρ(w,L)\rho(w,L) is a linear combination of retained rows of BbB_b whose costs are at most c(w,L)c(w,L). Consequently row(Bb)=Wb\operatorname{row}(B_b)=W_b for every type.

Proof. Use induction on the length of ww.

  • Length 0. The experiment ((),L)(\,(),L) was pushed initially. When it was popped, it was either retained (and is its own combination) or it lay in the span of rows already retained at bb. Those rows were popped earlier, so by Lemma 1 they cost at most cLc_L.
  • Prepending an action. Let w=(a)⋅w′w=(a)\cdot w', where w′w' starts at t(a)t(a). By induction ρ(w′,L)=∑kλkβk\rho(w',L)=\sum_k\lambda_k\,\beta_k, a sum over retained rows βk\beta_k at t(a)t(a) with c(βk)≤c(w′,L)c(\beta_k)\le c(w',L). Then ρ(w,L)=∑kλkβkMa\rho(w,L)=\sum_k\lambda_k\,\beta_kM_a. Each βkMa\beta_kM_a is the row of a child that was pushed, with cost c(βk)+ca≤c(w,L)c(\beta_k)+c_a\le c(w,L). When that child was popped, it was retained or dependent on rows of cost at most its own. Substituting gives the claim.

Thus Wb⊆row(Bb)W_b\subseteq\operatorname{row}(B_b). Conversely each retained row is a legal experiment, so row(Bb)⊆Wb\operatorname{row}(B_b)\subseteq W_b. Both inclusions matter. An elimination residual is not an experiment, and the code never stores one as a witness. ▫\square

The same argument works with the packet’s simultaneous iteration Wbk+1=Wbk+∑a:s(a)=bWt(a)kMaW_b^{k+1}=W_b^k+\sum_{a:s(a)=b}W^k_{t(a)}M_a. That chain is increasing. 14.4.3 Proposition 5 (the grammar closes at fixed budget)

Every output coordinate of volume vv is a combination of input coordinates of volume at most vv. Consequently, for every legal word of any length, the product of the typed matrices applied to the truncated state of a placed graph equals the truncated state of the assembled graph.

Proof. Read off the table. open, intro and intro_adj use input volume v−sv-s or v−tv-t. pendant and the contexts use v−jv-j. Every other action keeps vv. The ordered-contexts note proves the extension and context cases. The formula for each action is exact on the untruncated kernel. Truncation keeps it exact because no output ever reads an input of higher volume. Induction on word length finishes the proof. ▫\square

14.4.4 Proposition 6 (legality is sound for assembly)

If a word is legal from the type of a placed graph, then sequential assembly never creates a duplicate edge or a loop, and the actual type of the assembled graph equals the typed end type.

Proof. Use induction over the word. open, intro and extend add a fresh vertex adjacent to at most one current terminal, so the two terminals are non-adjacent afterwards. intro_adj makes them adjacent through a fresh edge. join is legal only on two, where the terminals are non-adjacent, so the new edge is not a duplicate. cut is legal only on two_adj, where the edge exists. Contexts are glued through fresh interior copies and have no terminal edge (the OrderedContextAttachment check), so they keep the adjacency status and cannot repeat an edge. swap and the forget actions add no edges. ▫\square

Proposition 6 does not follow from any matrix identity. Squaring the join matrix gives the factor q2(s−t)2q^{2(s-t)^2}. That is the population of a multigraph with a doubled terminal edge, and the tests confirm it with an independent multigraph enumeration. The type split two/two_adj is what rejects this word. This is the “edge-status changes need boundary metadata” failure mode named in the packet, resolved here by one bit of type information.

14.4.5 Refused extensions

  • Three or more terminals. Allowing intro from two would require an unbounded family of types. The grammar refuses it. This is an implementation boundary, not a theorem that such operations are impossible.
  • Joins of two unknown blocks. These are bilinear and stay outside the linear setting. Gluing a fixed context is linear, and those operations are included.
  • State-dependent guards and minimum-zero normalization. Neither is modelled.

14.5 4. Certificates and costs (NX13-C)

The portable format is singularity.typed-operator-closure/1. It is a new schema. The single-space format singularity.operator-closure/1 is unchanged, and nothing is renamed or migrated. A bundle records the following:

  • each type’s identifier and dimension;
  • each action’s ordered source and target, its matrix with explicit rows and columns, and its cost;
  • each observation’s type, row and cost;
  • per type: the witness experiments (observation, start type, chronological word, row, cost), the observation coordinates, the nullspace and the pivots;
  • per action: the coordinates TaT_a with explicit shape.

Rationals are canonical [numerator, denominator] pairs. An optional provenance field holds the graph adapter’s volume convention, terminal labels, context graphs, coordinate lists and assembly rule. That field is descriptive only. Algebraic replay does not prove the adapter; Section 5’s enumeration does.

replay_typed_bundle decodes strictly. It rejects booleans, floats, noncanonical rationals, shape disagreements, unknown fields, order mismatches and oversize inputs. load_typed_bundle also rejects duplicate JSON keys and NaN or Infinity. Replay then calls verify_typed_certificate, which rechecks every identity, every witness, cost order, pivots, kernels, the inclusion MaNs⊆NtM_aN_s\subseteq N_t and the filtration. Replay never calls typed_closure. scripts/typed_contexts.py --replay disables both the closure and the adapter module while it runs, and a unit test disables the closure the same way.

17.1 1. Objects

Take vertices 0, ..., n-1, symmetric nonnegative integral edge weights w_uv, and nonnegative integral pinnings lambda_v. For a height vector h of nonnegative integers put

A zero weight is the same thing as a missing edge. 17.2 2. The support expansion (proved)

Lemma 1. Phi_S is exactly the part of the multivariate series log F_w whose monomials use every vertex of S and no other vertex.

Proof. F_w is a formal power series in x_0, ..., x_{n-1}, with coefficients in Z[q] and constant term 1, so log F_w is well defined. Write Psi_A for the part of log F_w whose monomials have support exactly A. Setting x_v = 0 outside T is a ring homomorphism. It commutes with log and kills exactly the monomials whose support is not contained in T. Hence log Z_T = sum_{A subset T} Psi_A. Möbius inversion on the Boolean lattice gives Psi_S = sum_{T subset S} (-1)^{|S|-|T|} log Z_T = Phi_S. ▫\square

Corollary 2. Phi_S = O(x^{|S|}): each monomial of Psi_S has every exponent x_v, v in S, at least one.

Lemma 3 (disconnected supports vanish). If S is not connected in G_w, then Phi_S = 0.

Proof. Write S = A ⊔ B with both parts nonempty and no positive edge between them. Take T ⊆ S and a height vector h supported in T. The cross terms w_ab h_a h_b, with a ∈ A and b ∈ B, vanish because those weights are zero. Every other term involves only T∩A or only T∩B. So the energy splits, and Z_T = Z_{T∩A} Z_{T∩B}. Then log Z_T = f(T∩A) + g(T∩B). An alternating sum over T ⊆ S of a function of T∩A alone factors through sum_{T_B ⊆ B} (-1)^{|B|-|T_B|} = 0, because B is nonempty. The same holds for g, using that A is nonempty. ▫\square

Lemma 4 (what Phi depends on). Phi_S depends only on the decorations d_v for v ∈ S and the internal weights w_uv for u, v ∈ S. It is unchanged by any bijection of S that preserves both.

Proof. For T ⊆ S, the expanded energy of a height supported in T involves only these quantities. A relabelling that preserves them permutes the heights and preserves volume and energy. ▫\square

Theorem 5 (support expansion). For every R ≥ 0,

logFw≡∑Sconnected in Gw,|S|≤RΦS(w)(modxR+1). \log F_w\equiv\sum_{S\ \text{connected in }G_w,\ |S|\le R}\Phi_S(w)\pmod{x^{R+1}} .

Proof. By Lemma 1, log F_w is the sum of Psi_S over nonempty S. The supports with |S| > R contribute nothing modulo x^{R+1} by Corollary 2. The disconnected ones contribute nothing by Lemma 3. ▫\square

The unweighted form of this theorem is the existing SNG-F55 locality result. What is new here is the weighted, per-vertex-pinned statement. Its consequence is that a zero weight behaves exactly as an absent edge.

17.3 3. The union-graph difference identity (proved)

Compare two weightings (w, lambda) and (w', lambda'). Let D be the set of endpoints of every edge whose weight changes, together with every vertex whose pinning changes. Let U be the union graph: it has an edge uv whenever w_uv > 0 or w'_uv > 0.

Theorem 6. Modulo x^{R+1},

logFw′−logFw≡∑Sconnected in U|S|≤R,S∩D≠⌀(ΦS(w′)−ΦS(w)). \log F_{w'}-\log F_w\equiv\sum_{\substack{S\ \text{connected in }U\\ |S|\le R,\ S\cap D\ne\varnothing}}\bigl(\Phi_S(w')-\Phi_S(w)\bigr).

Proof. Each of G_w and G_{w'} is a subgraph of U. So a set connected in either graph is connected in U. By Lemma 3 we may therefore sum both expansions of Theorem 5 over all U-connected S with |S| ≤ R; the added terms are zero. Now suppose S ∩ D = ∅. Every changed edge has both endpoints in D, so no changed edge meets S. In particular, no internal weight of S changes. No weight incident to a vertex of S changes either, so the weighted degrees on S are the same. No pinning on S changes. By Lemma 4, Phi_S(w') = Phi_S(w). Subtracting the two sums leaves only the supports that meet D. ▫\square

Why the three naive filters are wrong. Each failure below is exhibited by an exact test, test_union_difference_identity_and_naive_filters, on a path with 4 vertices at R = 3.

  • New-graph supports only. After a deletion, a support that was connected only through the deleted edge has Phi_S(w') = 0 and Phi_S(w) ≠ 0. This filter drops that term.
  • Old-graph supports only. After an insertion, a newly connected support has Phi_S(w) = 0, and this filter drops it.
  • Supports containing both endpoints of a changed edge. A singleton {u} contains only one endpoint, yet its decoration d_u changes, so Phi_{{u}} changes. This happens in the mandatory two-vertex example below. For a change to the pinning of a single vertex, “contains every endpoint” coincides with “meets D”.

17.5 5. Cache soundness (proved)

A support’s memo key is (k, decorations, weighted internal edges) after relabelling S to 0..k-1. The relabelling minimises the edge list over orders that respect the vertex classes (decoration, sorted incident internal weights). When the number of such orders exceeds CANONICAL_LIMIT, the sorted vertex labelling is kept instead. Either way, the key is a complete description of a decorated, weighted graph that is isomorphic to S. Two supports with equal keys are therefore isomorphic in the sense of Lemma 4, and they have equal Phi. Moreover, Phi is computed from the key alone (_phi), so a cache entry is correct by construction. Cache slots also carry R and the convention string.

Consequences:

  • There are no false collisions across graphs. Sharing one cache between unrelated graphs and truncation depths is safe (test_cross_graph_cache_isolation). The packet’s warning about a set-only fallback key does not apply, because the fallback key here is the full labelled description, not a vertex-set name.
  • The labelled fallback loses only sharing (test_labelled_fallback_keys_are_exact forces it everywhere and gets identical logs).

17.6 6. Update algorithm and its locality (proved)

apply_local_changes(comp, changes) runs in five steps.

  1. It validates every change against the current state before changing anything. A stale patch, whose recorded old value differs from the current one, raises ValueError. So does a duplicate target, and so does an out-of-range vertex. In all three cases the state is left untouched.
  2. It enumerates the U-connected sets with |S| ≤ R that meet D. It does this by growing from the least marked vertex while avoiding earlier marked vertices (connected_sets_meeting). Adjacency is read only at members of the growing set.
  3. It reads the old keys from the support index; a support missing from the index is one that was disconnected in the old graph. It then applies the changes and computes the new keys, or none for a support that is now disconnected.
  4. It adds Phi(new) - Phi(old) to log F, with an absent side counted as zero, and updates the support index.
  5. It optionally emits a singularity.locality-update/1 record (section 7).

By Theorem 6 the result is exactly the recompiled logarithm. By Theorem 5 and the correctness of the index, the new support index equals the recompiled index.

Proposition 7 (local update cost). Let Delta_U be the maximum degree of U and N the set of vertices within U-distance R-1 of D. Assume that dictionary operations take unit time.

  • Every affected support lies inside N. A connected set of at most R vertices that meets D has every member within distance R-1 of D.
  • The number of affected supports is at most |D| · sum_{k=1}^{R} (k-1)! Delta_U^{k-1}. Here is the proof. Grow a connected k-set from a vertex of D by repeatedly adding a neighbour of the current set. At step j there are at most j·Delta_U choices, so there are at most (k-1)! Delta_U^{k-1} growth sequences, and every such set arises from one of them. Literature gives sharper bounds of the form (c·Delta)^{k-1}; they are not needed here.
  • The work per affected support depends only on R, Delta_U and the decorations and weights inside N. That work is one key canonicalisation, costing at most CANONICAL_LIMIT · R^2 comparisons, and two cache lookups. On a cache miss, computing Phi enumerates 2^k subsets and sum_{j ≤ R} C(j + c - 1, c - 1) profiles per restricted block. The exponents are at most R^2 · max d_v. The coefficients of Phi are functions of the key alone.
  • Updating log F costs R+1 polynomial additions per changed support and R+1 for the final merge. Their exponent range is bounded as above. The bit size of the coefficients of log F, however, does depend on the whole graph, because log F sums contributions from every support in the graph.

So, after setup, the number of supports touched, the polynomial operations and the cache traffic depend only on the decorated radius-(R-1) union neighbourhood of D. They do not depend on n. The only n-dependent quantities are the bit lengths of the global sums. The scaling receipt below measures both.

The update does not promise constant-time output of the full series. Formal exponentiation costs R(R+1)/2 polynomial products, and it touches every coefficient. The operation count of that query is independent of n, but its operands carry n-dependent coefficient sizes.

17.7 7. Update records and replay

A singularity.locality-update/1 record stores the following fields:

  • the baseline specification (n, the positive weights, the pinnings, and the energy unit as [numerator, denominator]);
  • the baseline logarithm;
  • the exact changes, as {kind, target, old, new};
  • affected_endpoints (the set D);
  • declared_union_edges, the edges of U among the vertices of the affected supports;
  • the list of affected supports, each with its old and new contribution or null;
  • result_log.

Polynomials use the existing polynomials.polynomial_to_json encoding, [exponent, numerator, denominator].

verify_local_update replays a record without using the incremental code.

  1. It rebuilds the old and new specifications, checking every old value.
  2. It checks completeness. It recomputes U from the two specifications and takes the ball of radius R-1 around D. It then forms every subset of at most R ball vertices, keeps those that meet D and are U-connected by a direct search, and requires the listed supports to be exactly these.
  3. It recomputes every listed contribution from its definition, support_contribution_by_definition. That function enumerates heights supported in each T ⊆ S with the edge-difference energy and uses no memo and no factorisation. A side must be null exactly when the support is disconnected in that version. As a by-product, this also confirms that disconnected supports have zero contribution.
  4. It checks that result_log equals the baseline log plus the listed corrections.
  5. Optionally, it compares exp(baseline log) and exp(result log) with direct_series.

A digest would not be enough here, because a hash cannot show that an omitted support was zero; step 2 is what does that. The baseline logarithm is trusted unless step 5 runs. The completeness check is exponential in the ball size, so it is budgeted.

Proposition (incremental locality). Let F_w be the height series of a nonnegative integral weighted energy with per-vertex pinning. Let D be the set of vertices touched by a change of weights or pinnings, and let U be the union of the old and new positive-weight graphs. 17.10 10. Limitations and open items

  • The scope is nonnegative integral weights, or rational weights with a declared unit. Negative or signed energies, continuous weights, vertex deletion or insertion, and changes to n are not handled.
  • The n-independence in Proposition 7 concerns support counts, polynomial-operation counts and cache traffic, and it assumes unit-time dictionary operations. Coefficient bit sizes of the global log and series grow with n, roughly R log n bits for the series. Wall times are measured on one machine and are not a proof.
  • The bound in Proposition 7 is fixed-parameter: it is useless for large R or dense union graphs.
  • Copying updates (in_place=False) and records that include the baseline cost O(size). Only in-place updates without a record are local.
  • The baseline logarithm in a record is trusted unless the direct oracle runs. Replaying completeness is exponential in the size of the radius-(R-1) ball and is budgeted.
  • Boundary-charge-aware updates (charges.py, separator_compiler.py), dynamic canonicalisation, and moment or cycle extensions under updates are left to later pushes.
  • locality.connected_supersets copies the full adjacency on each call, which costs O(n). This module therefore has its own local enumerator, which is tested against brute force. A lazy version of the shared function would let both modules use one enumerator; that is a suggested change to an existing file.
