# NX36: states, experiments, evidence and limits

## What this companion establishes

The NX36 programme develops a single question across graph interfaces, dynamical systems, arithmetic populations and measured application pilots: which differences can a declared experiment language reveal, at what cost, and with what uncertainty? This implementation companion records the contracts that make that question decidable in bounded cases. It accompanies the graph monograph and the independent frontier companion. It does not replace their definitions or turn their remaining reconstruction questions into solved problems.

An experiment has a population, an intervention, an observation and a cost. Each part is needed. A rank calculation without an uncertainty set does not certify reliable identification. A panel optimum without its candidate catalogue does not certify optimality over every legal physical experiment. A finite coefficient prefix without a generation theorem does not certify equality of infinite series. The modules below return explicit finite answers, witnesses, or resource-bound refusals under recorded assumptions.

Let the original candidate population be \(\Omega\), the target be \(\tau:\Omega\to\mathcal T\), and the possible outputs of experiment \(e\) on candidate \(\omega\) be \(Y_e(\omega)\). For independently reset scalar experiments a panel \(P\) identifies the target exactly when

\[
\forall\omega,\omega'\in\Omega,\quad
\tau(\omega)\ne\tau(\omega')
\Longrightarrow
\exists e\in P:\ Y_e(\omega)\cap Y_e(\omega')=\varnothing.
\]

This statement concerns closed output sets: touching endpoints are ambiguous. When the same nuisance variable persists across observations, the correct object is the joint attainable set \(Y_P(\omega)\); scalar interval projections can discard information. When interventions share physical history, the state and nuisance variables must persist through the whole word. The implementation keeps these models distinct.

For a finite state language, observable rows are generated by

\[
W_0=\operatorname{rowspan}(L),\qquad
W_{k+1}=W_k+\sum_eW_kM_e.
\]

At stabilization \(W_{k+1}=W_k\), every future legal reading lies in \(W_k\). Its annihilator
\(N=\bigcap_{w\in W_k}\ker w\) is invariant under the generators, so \(V/N\) is an exact observational quotient. Retained basis rows carry actual words; linear combinations certify completeness but are not silently treated as executable experiments. Positive cost ordering permits span pruning for cheapest single witnesses. Robust maximum-margin selection and shared-panel optimization require additional searches because a longer dependent experiment may amplify a signal or share costs differently.

For persistent zonotopic uncertainty, a rational contrast \(a\) certifies disjointness if

\[
\left|a^\mathsf T(c_\omega-c_{\omega'})\right|
>
\|G_\omega^\mathsf Ta\|_1+
\|G_{\omega'}^\mathsf Ta\|_1.
\]

The two generator matrices represent feasible nuisance variables in two alternative worlds. Within either world their columns remain shared across the panel. Feasibility certificates and contrast certificates give complementary primal and dual evidence. An optimizer timeout supplies neither a disjointness theorem nor an overlap theorem.

For target recovery, an exact decoder \(D\) satisfies \(DA=H\) on the admissible state subspace. This identity proves noiseless recovery. A separate norm bound controls \(D\eta\). Two panels can have the same rank and dramatically different amplification. Coordinate rescaling changes coefficient norms, so source units and the declared observation metric are part of a conditioning certificate.

## What changed in practice

The thermal work expands from a six-candidate example into several distinct experimental models. The original 112-test pool remains available for fair comparison. A separate 79-member fault population keeps all masks with at most two faults on twelve explicitly selected plate bonds. Some finite catalogues identify fewer response classes than original masks; the receipts retain those blind pairs. A maximal observable quotient is useful, but it does not identify faults that the experiment language cannot distinguish.

Persistent-error geometry can certify a joint separation that every independent scalar projection misses. Adaptive policies can sometimes save experiments, but the retained original thermal pool gives an honest case where adaptive and static costs coincide. Shared-history experiments use a different contract and can exploit information collected before a reset erases it. Their savings are compared only with a static language using the same controls, sensors, initial-state assumptions and noise model.

Low-rank fault transport separates a reusable nominal calculation from each fault correction. If a blocked bond has incidence vector \(b\), then its discrete transition has the form

\[
A_\gamma=A_0+\gamma bb^\mathsf T,
\]

with the sign determined by removing conductance from the nominal conservative update. The implementation checks this sign against independent neighbour-flux evolution. Resolvent or coefficient Woodbury identities operate on small fault-index matrices, while the full state and sensor dimensions remain in the source binding. A rank-one algebraic identity does not automatically transport a nominal uncertainty certificate to a damaged model; each claimed bound must be valid for the actual fault/sensor/protocol combination.

The graph frontiers gain stronger tools without assuming their general conjectures. Exact integer quotients expose congruence constraints hidden by rational row spaces. A rationally realizable state need not have an integer preimage. Parameter receipts distinguish rank at \(q=1/2\) from rank on an interval. Structural graph searches report their constructor bounds and can establish exclusions for promised families; failure to find a pair in a finite search does not rule out a larger realization. The effective-prefix work supplies genuine infinite conclusions in restricted sectors by proving the rule that advances coefficients.

The period work follows the same discipline. A differential observable is generated by covariant derivatives of a row, and a reduced connection must satisfy an exact moving-basis identity. If \(B\) is a row reduction of the original system \(y'=Ay\), then

\[
B'+BA=DB,\qquad r=\rho B
\]

proves that \(z=By\) obeys \(z'=Dz\) and preserves target \(ry=\rho z\). On an overlap \(\widetilde B=GB\), the reduced connections must satisfy

\[
\widetilde D=(G'+GD)G^{-1}.
\]

Local gauge identities alone do not prove loop holonomy. The monodromy receipts therefore bind source equations, paths, normalization and independent validated continuation. Numerical proximity to an integer matrix does not authorize exact integer recovery without a lattice premise.

## Consequences for the wider programme

The project now has a reusable path from a mathematical observation to a declared experiment, a costed design, an uncertainty-aware distinction and a portable certificate. This makes the earlier graph interfaces operational and lets the same questions be asked of thermal faults, arithmetic states and period targets. It also makes negative results actionable: a blind direction says which information the current language lacks, and a poorly conditioned decoder says which experiment needs a stronger signal.

Three broad graph research questions remain separate from completing this implementation programme: efficient reconstruction beyond the graph classes already proved, completeness or a full-series collision for fixed pinning, and realization of surviving symmetric-interface ambiguities. These require new mathematics. The modules and receipts in this companion improve the tools, constraints and experimental evidence available for those questions.
