# Physical sensor design, entirely offline

This application performs two source-bound studies on measured physical systems: the complete UCI hydraulic corpus and a bounded synchronized MAFAULDA microphone/accelerometer subset, followed by a separately frozen audio confirmation. Open `Sensor_Design_Research.html` for the illustrated report. These are retrospective measurement replays, not newly acquired hardware experiments or counterfactual stimulus studies.

The useful positive signal is a six-sensor hydraulic panel chosen with a development-time erasure requirement: held-out mean component balanced accuracy is 86.33%, versus 81.03% for the same additive classifier with all fourteen sensors. Its logged scalar count is 13,320 versus 43,500 per cycle. A stronger full-feature classifier reaches 89.50%, so this is a promising constrained candidate rather than global superiority. Two-sensor selection loses 6.96 percentage points on the held-out accumulator task. Exact selection ties greedy and optimally pruned greedy. Audio reductions do not preserve the declared accuracy margin on either held-out evaluation; microphone-only matches the seven-channel panel on the small fresh confirmation. The package retains these negative findings.

## Reproduce from retained evidence

From the repository root, install the optional application dependencies with `python -m pip install -r applications/sensor_replay/requirements.txt`. The standard-library core remains unchanged. Run `python applications/sensor_replay/verify_hydraulic.py applications/sensor_replay/hydraulic_v1`, `python applications/sensor_replay/audio_v1/verify_audio_study.py`, and `python applications/sensor_replay/audio_v1/confirmation/verify_confirmation.py`. The hydraulic checker imports no study selector and independently rebuilds all mask predictions, exact rational feasibility, restricted greedy pruning, erasure constraints and published test metrics. The audio checkers use independent distance and subset implementations.

Run `python applications/sensor_replay/retrain_from_features.py applications/sensor_replay/hydraulic_v1` to refit all 56 training-only models and compare both selection and test score tables bit for bit in the pinned environment. This deterministic training reproduction is separate from independent optimum verification. For a new raw-to-results hydraulic replay, run `python applications/sensor_replay/run_hydraulic.py --archive /path/to/hydraulic.zip --output /path/to/new-output`. An absent archive is downloaded from the official UCI URL and its SHA-256 must match the retained source. A new output directory is required; the frozen original will not be overwritten.

For complete raw audio feature reproduction, run `python applications/sensor_replay/audio_v1/acquire_sources.py` and then `python applications/sensor_replay/audio_v1/verify_raw_features.py`. The downloader retrieves only the 42 declared ZIP members (279,004,318 compressed bytes), checks source member hashes and CRCs, and writes to ignored `audio_data`. The raw feature checker re-extracts both phases into temporary files without altering frozen evidence. Raw audio is not redistributed; the source landing page supplies no explicit dataset licence. Feature-level offline verification requires no download.

Run `PYTHONPATH=src python applications/sensor_replay/interval_diagnostic.py applications/sensor_replay/hydraulic_v1` to replay a separately labelled post-hoc conservative-envelope analysis with Singularity's existing exact robust-coverage engine and independent exhaustive oracle. Twelve of eighteen component-level distinctions lack an individually separating feature coordinate in the empirical development min-max boxes. This is failure of that conservative sufficient certificate, not proof of physical indistinguishability. The empirical classifier and interval design contracts are intentionally different.

## Frozen hydraulic protocol and finite theorem

All 2,205 cycles are retained. Fourteen physical channels are eligible; virtual channels CE, CP and SE, and the stability flag, are excluded from predictors. All cycles with a common four-component severity tuple share a split. A fixed SHA-256 ordering gives 86 training combinations (1,575 cycles), 28 selection combinations (305 cycles), and 30 held-out combinations (325 cycles). Every component severity is represented in every split. The claim concerns unfamiliar combinations of familiar severities on one rig. True acquisition-session identities and independent machines are unavailable.

For each component t and sensor subset S, the fixed classifier's selection balanced accuracy B_t(S) is an exact rational number after its floating-point predictions have been computed. Feasibility requires B_t(S) >= B_t(full) - 1/50 for every component. All 16,384 masks are enumerated without assuming that adding a sensor improves classification. The objective is lexicographic: sensor count, original scalar sample count per 60-second cycle, integer mask. Among 3,311 feasible masks, FS1+TS1 is optimal and also chosen by greedy and optimally pruned greedy. Erasure feasibility requires this same condition for the intact panel and every one-sensor deletion. Among 69 qualifying masks, the six-sensor panel PS3, EPS1, FS1, FS2, TS2, VS1 is optimal. These are minimum costs for the frozen classifier and selection table, not universal physics theorems.

Selection and test use complete cycles, with nineteen fixed descriptors per physical sensor. Each sensor/component classifier is a class-balanced ExtraTrees model trained only on training combinations. Selected-sensor log probabilities are added. The stronger all-feature reference has its own frozen configuration and is not used for subset selection. Costs are declared sensor and sample counts; no hardware price, latency, energy or new operating-speed benefit is claimed.

The grouped bootstrap resamples complete fault combinations. The lowest accumulator pressure has only two test groups; some replicates omit classes as declared in the original protocol. These intervals are exploratory, and do not establish noninferiority. Stable/transient subgroup macro scores average only the levels present in each subgroup. Even the six-sensor erasure criterion fails to transfer for every task/deletion: deleting FS1 gives 85.17% pump balanced accuracy, below the full-model test score minus two percentage points.

## Audio protocol and interpretation

The original pilot uses 24 complete five-second records, three conditions, eight nominal speed groups, and seven diagnostic channels. Tachometer data are excluded. Whole speed groups are assigned to training, selection and test; no windows from the same recording cross partitions. Exact, greedy and optimally pruned greedy choose the same one-channel panel. It passes the six selection records and gets only two of six test records correct. The full panel gets six of six. This is negative transfer evidence from a tiny pilot, not a full MAFAULDA benchmark.

After that failure, a new confirmation protocol freezes the union of all development-optimal singleton panels and comparator panels before acquiring eighteen new records at intervening nominal speeds. Training is unchanged. The original singleton gets 12/18, the two-channel union 15/18, the full seven channels 16/18, and microphone-only 16/18. The union does not meet the two-percentage-point preservation margin and does not outperform the simpler microphone baseline. Frozen v1 bytes remain unchanged. `audio_v1/protocol_errata.json` corrects one phrase: integrity decompression preceded the first freeze, while numeric parsing, features and modelling followed it.

## Evidence boundaries and next experiment

Independent replay verifies finite optimization, arithmetic, source identities and saved measurement-model outputs. It does not formalize the physical classifier, prove that empirical noise boxes hold universally, establish device-independent transfer, or create measurements for sensor positions and stimuli absent from the recordings. The next justified work is a larger machine/domain-held-out array study with nuisance-aware selection and a protected confirmation set. This study establishes an executable evidence pipeline and a constrained hydraulic candidate; it does not establish a general exact-selection advantage.

The source survey includes UCI hydraulic data, MAFAULDA, MIMII, MIMII DUE, ToyADMOS, the DCASE mono derivative, IDMT electric engines, CWRU, NASA IMS and multi-view Real-IAD. Only the two explicitly described datasets were executed. Source URLs, licences where published, hashes, protocols, features, score tables, predictions and independent checkers accompany the report.
