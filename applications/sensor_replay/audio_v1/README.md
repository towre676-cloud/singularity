This directory preserves a negative physical audio/vibration selection pilot and its separately frozen new-recording confirmation. Read FINDINGS.md for the outcome and evidence limits. The original 24-recording study and new 18-recording confirmation use disjoint whole recordings. The fixed source is the UFRJ MAFAULDA test rig; these are real physical recordings replayed in software, not newly simulated waveforms.

Install NumPy to replay the feature-level results. From this directory run `python verify_audio_study.py`, then `python confirmation/verify_confirmation.py`. These independent verifiers preserve the frozen evidence and need neither network access nor raw recordings. SciPy is needed only for raw-signal feature extraction. The feature arrays are small and contain seven diagnostic channels with 14 descriptors each; the tachometer is excluded. Source member receipts include official archive URLs, member names, compressed offsets, CRC32 values and individual SHA-256 hashes.

The original execution scripts are preserved as run_audio_study.py and confirmation/run_confirmation.py. They can regenerate calculations, but they write output snapshots; perform new runs in a copy if retaining the frozen files. The confirmation intentionally binds the original frozen selection snapshot and results by hash, so rewriting those historical files is not a valid way to extend the study. Feature-level independent verification is the default reproduction route.

For complete raw-signal reproduction, install NumPy and SciPy, run `python acquire_sources.py` and then `python verify_raw_features.py`. The downloader reacquires only the 42 frozen original members using byte ranges from official archives, verifies each compressed and raw SHA-256 plus ZIP CRC32, and places them in a sibling audio_data directory. It refuses a server that ignores byte ranges. The feature verifier recomputes both feature arrays in temporary directories and compares them without rewriting any frozen evidence. Both scripts resolve paths from their own location, so the study can be moved within a repository. Raw payloads are excluded from the distributable. No physical sensor acquisition, novel placement, new excitation, measured hardware cost or independent-machine validation is claimed.
