# Thermal fault identification on the DynaComp plate

Run `python scripts/thermal_diagnostics.py` from the repository root to reproduce the complete source-pinned experiment and write its exact results. Run `python scripts/thermal_diagnostics.py --check` to check the retained result without replacing it. The default experiment uses only Python's standard library and the files already in this repository. No account, data download, numerical package, or observed fault dataset is needed.

The source is DynaComp commit `cd788c7ac695728e3f5b22056a0f99a2c1e1463c`, function `plate_model` in `src/dynacomp/thermal.py`. The retained `source_fixture.json` contains its full 144-state rational model, construction metadata, and source hashes. `dynacomp_plate_source.py.txt` retains the exact generating function. The receipt checks the imported model against a separate undirected-edge stencil construction. To compare with a local checkout of the original source as well, run `python scripts/thermal_diagnostics.py --check --dynacomp-source /absolute/path/to/DynaComp`. The optional check verifies the source module hash before importing its generator.

The six candidates are a nominal plate, uniformly halved conductance, halved heater gain, doubled ambient loss, one blocked bond immediately left of the central heater, and its reflected blocked bond on the right. These are supplied mathematical fault hypotheses. Their probabilities, real equipment fidelity, preparation precision, sensor precision, and experimental costs have not been learned from measurements. The independent reset uncertainty, measurement error, and model-unit cost contract are explicit in the retained JSON. No earlier DynaComp reduction certificate is reused for altered faults or sensors.

The original central heater and corner-mean sensor cannot tell the two reflected blocked bonds apart, even with unlimited scalar heater protocols. Adding localized central sensor averages breaks this symmetry. Singularity computes a cheapest exact panel and a cheapest panel robust to the declared measurement and reset errors, compares greedy selection, and independently checks all 672 candidate readings by direct neighbor-flux simulation. With reset radius and sensor error both 0.01 in model units, the exact robust planner costs 20, greedy selection costs 31, and a feasible fixed twenty-step protocol costs 44. Cost optimality applies to the finite declared experiment pool, rather than every physically possible heater or sensor protocol.
