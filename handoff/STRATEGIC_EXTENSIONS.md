# Strategic directions after P01–P36

This file reconciles the early impact discussion with the current release. The original 36 acceptance units are complete. X01–X04 below remain discussion labels, not a second acceptance ledger. The P37–P72 proposal inventory also requires a current evidence audit before a task is accepted. Start from `docs/papers/second_paper_choice.md`, which distinguishes achieved results from precise open questions.

## X01: reusable terminal responses — implemented foundation

Ordered terminal kernels, correct terminal-volume ownership, explicit graph gluing, marked gluing and Whitney-twist discrepancies are implemented in `terminals.py` and tested independently. SNG-F41–SNG-F45 establish the relevant identities and structural bounds. The straight-versus-twisted pairing is no longer just a suggested calculation; the identical-block positivity theorem and exact visibility mechanism are in the manuscript.

The next useful question is a new class of response-preserving transformations or a sharper characterization of which attachment grammars need which marks. Do not rebuild a proposed kernel from scratch or report the three-vertex rooted-path example as the principal result. Preserve shared-terminal edge validation and charge terminal volume exactly once.

## X02: minimal contextual interfaces — substantial exact machinery exists

`contexts.py` implements symmetric-context quotients, probe reconstruction and realization constraints. `charges.py` implements boundary-charge interfaces, dominating-block closure transport and ordered charge charts. SNG-F53/F54 show how a compiled interface can transport answers across future contexts; SNG-F62 covers complete ordered charge observations. Resource savings are stated for declared models and retained experiments, not every graph encoding.

The surviving realization problems are substantive: decide whether actual blocks realize the remaining symmetric-interface candidates at budget 38 with a terminal edge or 11 without. Abstract null vectors are not automatically graph-realizable differences. A useful next result would prove a necessary graph-realizability constraint, exclude a candidate, or construct actual blocks with an all-claimed-coordinate check. Finite agreement alone cannot establish contextual equivalence at every budget.

Connection matrices, conditional partition functions and graph algebras are established background. Any new interface theorem needs an explicit context class, representation model, arithmetic cost and literature comparison. Matrix rank alone is not a universal lower bound on arbitrary nonlinear encodings.

## X03: delayed visibility and positive reconstruction — achieved family theorems

Unbounded first-separation volume is established by explicit pendant-cycle and Whitney-twist families. Connected-support locality gives a coefficient compiler, and SNG-F56 identifies the first-cycle contribution. SNG-F57 reconstructs every simple 2-regular interior of known order n through budget floor(n/2); this worst-case budget is sharp for n>=6. The selected second paper develops that coherent result with exact finite receipts.

The next frontier is efficient reconstruction beyond cycle interiors, or the scalar fixed-pinning inverse problem. For

\[
A_H(x,q)=\sum_h x^{\sum h}q^{E_H(h)+2\sum h^2},
\]

prove completeness or exhibit a genuine full-series collision. The complete moment enrichment of SNG-F58 is a separate achieved result; its enormous separating-volume construction does not answer this specialized question or provide an efficient isomorphism method. At bounded budget, the connected decorated-support statistics are sufficient, but the converse implication is not proved because their polynomial contributions can cancel.

A concrete algorithmic continuation is a hybrid compiler using separator methods inside connected footprints. Its exactness, cost and benefit must be demonstrated rather than inferred from having both component engines.

## X04: matched-cost observation benchmarks — a separate experimental program

The repository retains exact compiler, closure and graph-comparison experiments. Those do not establish downstream learning utility. If pursuing that impact route, declare input populations, explicit graphlet and Weisfeiler–Leman baselines, matched compute budgets and a question those observations must answer. Separate graph discrimination from prediction. Learning claims require data splits, leakage checks, uncertainty and reproducible baseline implementations.

The strongest immediate mathematical continuation is a new inverse theorem, a realization obstruction or an exact hybrid method with a measured advantage. Broader application claims should follow those results. The Euler lift expresses local information analytically; it cannot restore correspondence that the local observation discarded.
