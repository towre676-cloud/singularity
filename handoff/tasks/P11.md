# P11 — Recover span by bounded-box subtraction

**Dependencies:** P09–P10. **Objective:** produce exact span-marked tree populations without enlarging every message by both extrema.

**Inspect first:** `src/singularity/transfer.py`: `bounded_height_histogram(..., min_zero=True)`; `src/singularity/heights.py`: `marked_coefficients`; `tests/test_transfer.py`: `test_global_shift_subtraction_on_disconnected_forest`; `docs/chapters/13_research_program.md`. Minimum-zero subtraction already exists; an exact-span tree API is still to be inspected or added.

**Work:** define \(C_H\) as the full bounded-box histogram and \(C_{-1}=0\). Prove \(D_H=C_H-x^nC_{H-1}\) counts minimum-zero profiles with maximum at most \(H\). Then prove \(D_H-D_{H-1}\) counts exact span \(H\). Add a proposed `marked_forest_coefficients` API in `transfer.py` or a clearly named new module, returning the same `(volume,energy,span)` convention as the reference engine. Share computations only when reuse preserves declared truncations.

**Mathematical acceptance:** include \(H=0\), singleton graphs, disconnected forests and ranges crossing volume \(n\). Explain why translation changes volume but not energy, and why the two subtractions never produce negative final counts.

**Verification:** compare every marked cell with `marked_coefficients` for all small forests and P02; sum over span to recover normalized coefficients. A mismatch must fail loudly, with input data retained; never clip negative counts.

**Done:** bijective proof, stable marked output, exhaustive small checks and support-cost measurements. **Typical failure:** using componentwise shifts in the global subtraction, or forgetting the shifted volume budget for \(C_{H-1}\).
