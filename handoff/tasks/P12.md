# P12 — Extend messages to bounded separators

**Dependencies:** P10–P11. **Objective:** compute exact populations from an explicitly supplied tree decomposition, with checked structural assumptions.

**Inspect first:** `src/singularity/transfer.py`, `population.py`; `tests/test_transfer.py`, `test_population.py`; `docs/chapters/13_research_program.md`. `HeightPopulation` has an ordered-frontier recursion. It is not a supplied-tree-decomposition implementation. No `separators.py` or rooted-response module currently exists; proposed files must be created deliberately.

**Work:** add proposed `src/singularity/decomposition.py`, `tests/test_decomposition.py` and a JSON decomposition specification. Define bags, tree edges and root. Check tree connectivity/acyclicity, vertex coverage, coverage of every graph edge, and connected occurrence bags for each vertex. Choose a charge convention: assign each vertex and edge to one canonical owning bag, or prove introduce/forget/join rules after a checked nice-decomposition conversion. Specify bag-conditioned message meanings and gluing contractions before optimizing.

**Mathematical acceptance:** prove correctness by decomposition induction, retaining exact original labels and counting each charge once. Integrate safe volume truncation and span recovery. Separate \((H+1)^{w+1}\) bag assignments, sparse convolution work and coefficient bit complexity.

**Verification:** reject malformed decompositions; compare multiple valid decompositions of the same cycle, ladder and small clique against brute enumeration. Compare width-one results with forest transfer, including disconnected input handling.

**Done:** supplied-decomposition checker, exact engine, correctness proof and complete independent comparisons. **Typical failure:** renaming the existing linear frontier algorithm, accepting a decomposition missing an edge, or double-counting shared bag volume at joins.
