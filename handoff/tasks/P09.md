# P09 — Implement bounded-height tree messages

**Dependencies:** P02. **Objective:** establish a documented exact tree-message interface and its correctness theorem.

**Inspect first:** `src/singularity/transfer.py`: `_forest_order`, `_unrestricted_forest`, `bounded_height_histogram`; `tests/test_transfer.py`; `scripts/benchmark_transfer.py`; `docs/chapters/13_research_program.md`. The forest implementation is already present. Inspect, expose or extend its reusable conditioned messages; do not rewrite it merely to satisfy the roadmap title.

**Work:** state the message meaning for a rooted subtree with root height \(t\), inclusive bounds \(H,R\), and sparse `(volume,energy)` support. Derive \(F_v(t)=x^t\prod_u\sum_j q^{(t-j)^2}F_u(j)\). Make root selection and original vertex labels explicit if a public conditioned-message API is added. Document disconnected forest assembly separately. Keep cycle rejection; general graphs belong to P12.

**Mathematical acceptance:** prove by subtree induction that every vertex weight and edge energy is charged exactly once and multiplicities count all labeled profiles. Explain why deleting child messages after use preserves semantics. Distinguish height-state count from polynomial support and integer bit sizes.

**Verification:** retain `test_all_small_labeled_forests_randomized`, `test_relabeling_preserves_counts` and `test_cycles_are_rejected_and_bounds_validated`. Compare complete histograms on paths, stars, balanced trees and a branched asymmetric tree against `brute_bounded_height_histogram` and P02 where affordable.

**Done:** inspectable recursion proof, stable API meaning, independent checks and measured supports. **Typical failure:** charging a connecting edge twice, omitting the root's volume, or advertising state count alone as runtime complexity.
