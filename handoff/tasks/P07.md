There is currently no proof-assistant project in the repository. Proposed `formal/` paths below are new infrastructure, not existing verified results.

**Work:** choose and pin a supported Lean/mathlib or equivalent toolchain after checking its official documentation. Add proposed `formal/lean-toolchain`, `formal/lakefile.toml` and `formal/Singularity/Normalization.lean` if Lean is selected. Represent a finite nonempty labeled vertex type, an edge set and integer heights. Define volume and edge-square energy directly. Construct the bijection between nonnegative profiles and pairs consisting of a minimum-zero profile and a nonnegative translation. Establish coefficient finiteness before summing.

**Mathematical acceptance:** kernel-check injectivity, surjectivity, uniqueness of the shift, energy preservation and volume increment \(nt\). Derive the coefficient recurrence underlying \(B=(1-x^n)L\), including disconnected graphs; no complex analysis is required.

**Verification:** publish the clean-environment build command, dependency revisions and exact theorem names. Search submitted formal sources for `sorry`, `admit` and new axioms; inspect dependencies rather than treating that text search as sufficient verification.

**Done:** the real pinned build succeeds without admitted project lemmas. **Typical failure:** shipping pseudocode in a `.lean` file, formalizing only a finite example, or reporting a Python test as kernel verification.
