# P21 — Relate constrained heights to order polytopes

**Dependencies:** P20. **Objective:** identify the exact established lattice-count problem beneath an explicitly constrained height population.

**Inspect first:** `src/singularity/population.py`, P20's chamber module; `docs/chapters/13_research_program.md` §13.6; `docs/references.bib` entries for Stanley. Current `HeightPopulation` joint constraints do not by themselves implement arbitrary poset inequalities.

**Work:** define a finite poset with validated acyclicity and closure convention. Add proposed `src/singularity/orders.py` and `tests/test_orders.py` for assignments \(0\le a_i\le H\) satisfying \(i\le_Pj\Rightarrow a_i\le a_j\). Specify strict inequalities separately. Prove identification with lattice points in \(H\mathcal O(P)\), where \(\mathcal O(P)\subseteq[0,1]^n\) uses the same orientation of inequalities. State the order-polynomial argument shift caused by using \(0,\ldots,H\), rather than \(1,\ldots,H\).

**Mathematical acceptance:** derive the unweighted bounded-height count and map chamber tie rules to linear extensions. Then identify exactly what weighting by \(q^{E_G(a)}\) and volume adds: a weighted count on the same points, not automatically an ordinary Ehrhart polynomial in \(H\).

**Verification:** independently enumerate chains, antichains, a diamond and disconnected posets for several complete height ranges. Check chain binomial formulas and antichain \((H+1)^n\). Invalid cyclic relations must fail explicitly.

**Done:** precise comparison theorem, correct endpoint conventions, exact tests and a literature-positioning paragraph. **Typical failure:** confusing weak order-preserving maps with strictly increasing maps or inheriting ordinary polynomiality after introducing a quadratic weight.
