# P30 — Measure collision classes across invariants

**Dependencies:** P12, P14 and P29. **Objective:** compare exact invariant partitions on one fixed, complete population with inspectable memberships.

**Inspect first:** `scripts/census.py`, `results/small_census.json`; `src/singularity/invariants.py`, `heights.py`; P12's decomposition engine, P14's tensor and P29's manifest. The existing census reports class counts and terminal unresolved classes but does not yet provide the full requested multi-invariant membership dataset.

**Work:** extend the census through a new versioned output or add proposed `scripts/collision_census.py`. Compute exact Laplacian characteristic polynomials, binary cut-volume profiles, nested-pair tensors and local/marked height prefixes. Record each equivalence class's full graph IDs at every declared depth. Produce partition-refinement comparisons and first-discrepancy witnesses for selected collisions. Reuse separator algorithms only where a checked decomposition is available.

**Mathematical acceptance:** denominator and graph class are explicit for every percentage. Each claimed distinction has an exact witness; each unresolved pair retains its maximum tested volume. Polynomial-in-\(q\) comparisons and specialized comparisons are separate columns. Isomorphic relabelings must never inflate distinct-graph separation statistics.

**Verification:** independently recompute a stratified sample with compositions and chains, verify every class's internal equality and cross-class witness, and reconcile class counts with the original order-six baseline where scopes match. Release resource caps and aborted computations.

**Done:** complete memberships, exact witness packets, deterministic reports and stated bounds. **Typical failure:** publishing only a percentage, omitting hard unresolved instances, or inferring general reconstruction from complete separation in this finite population.
