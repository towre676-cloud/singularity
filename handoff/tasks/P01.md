# P01 — Freeze the coefficient semantics

**Dependencies:** Initial release. **Objective:** publish a versioned finite semantic contract before alternative representations accumulate.

**Inspect first:** `src/singularity/graph.py`, `heights.py`, `population.py`, `weighted.py`; `docs/chapters/01_orientation.md`, `02_graphs_lattices.md`; `tests/test_core.py`, `test_population.py`. These implementations already exist. Audit and extend their documentation rather than replacing their counting model.

**Work:** create proposed `docs/specifications/COEFFICIENTS-v1.md`. Specify labeled simple loopless nonempty graphs, nonnegative integer tuples, volume, quadratic edge energy, minimum-zero representatives, span, and inclusive volume truncation. Give exact input/output meanings for every public coefficient and population API. Distinguish a global additive shift from separate shifts on connected components. Explain signed heights in `Graph.energy`, positive masses in `WeightedGraph`, and whether normalization is available for each API. Publish zero-volume and singleton examples with exact sparse dictionaries.

**Mathematical acceptance:** prove the coefficient interpretation of \(B=(1-x^n)L\); explain why disconnected graphs still use one global factor here. Do not silently replace it by a product of component factors. Specify that marked counts retain original labeled multiplicity.

**Verification:** extend `HeightTests.test_local_normalized_and_marked_against_direct_products` and `TreeTransferTests.test_global_shift_subtraction_on_disconnected_forest` only where the audit exposes missing cases. Run `PYTHONPATH=src python -m unittest discover -s tests -v`.

**Done:** the specification, API docstrings, examples and manuscript agree, with a compatibility note for any change. **Typical failure:** calling a tested finite prefix the complete series, or quotienting by graph automorphisms without declaring a new population.
