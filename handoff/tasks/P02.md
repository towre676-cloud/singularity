# P02 — Add independent level-chain enumeration

**Dependencies:** P01. **Objective:** obtain an independent enumerator whose input objects are nested sets, rather than height compositions.

**Inspect first:** `src/singularity/heights.py`: `threshold_sets`, `nested_energy`, `weak_compositions`, `marked_coefficients`; `docs/chapters/03_nested_heights.md`; `tests/test_core.py`. The existing nested-energy evaluator checks a height tuple; it does not independently generate every admissible chain.

**Work:** add proposed `src/singularity/chains.py` and `tests/test_chains.py`. Enumerate chains \(\varnothing\ne S_h\subseteq\cdots\subseteq S_1\subsetneq V\), allowing equal consecutive sets, bounded by \(\sum_r|S_r|\le R\). Include the empty chain once. Return sparse counts indexed by volume, energy and span. Explain the bijection with minimum-zero assignments, including repeated levels for height gaps. Budget the search explicitly; never silently sample.

**Mathematical acceptance:** derive volume \(\sum_r|S_r|\), span \(h\), and energy \(\sum_r|\delta S_r|+2\sum_{r<t}e(S_t,V\setminus S_r)\). Prove the cross-term convention counts an undirected edge once. An implementation calling `marked_coefficients` internally is not independent.

**Verification:** compare complete marked dictionaries against compositions for every simple graph through four vertices at a declared bound; include singleton graphs, disconnected graphs, all-zero heights and profiles such as `(0,0,3)`. Independently compare chain energies with direct edge squares.

**Done:** release test population, bounds, full equality checks and a short proof. **Typical failure:** requiring strict nesting, omitting repeated sets, or substituting absolute-difference cut energy for the quadratic energy.
