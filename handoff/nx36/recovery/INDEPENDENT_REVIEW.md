# Integration review

The six implementation groups exchanged independent mathematical and code
reviews before final acceptance. The integration test run preceded these
reviews; a final run and deterministic receipt replay follow the fixes.

| Finding | Consequence | Correction and regression |
|---|---|---|
| Zero leading coefficient in the exact factored-polynomial checker | The zero polynomial could be reported zero-free | Require a nonzero leading coefficient; reject zero and noncanonical degrees |
| Differential-closure receipt checked containment and closedness alone | An unrelated invariant mode could inflate a purported minimal observable space | Check independence and equality with the submodule generated by target derivatives; reject forged extra and dependent rows |
| Forecast decoder on an affine constrained state omitted its offset | Correct perturbation weights could still give a wrong absolute target | Retain the exact affine offset in the decoder contract |
| Ordered signatures discarded the coordinate frame | Physically incompatible paths could share a key or compose | Preserve frame metadata and reject incompatible frames |
| Remote-query costs used sequence index instead of physical time | Repeated-block protocols could be underpriced | Bind stride, offset and physical step in query/cost calculations |
| Evaluator menus did not require the same sensor across candidates | A selector could compare different physical measurements | Validate sensor identities across every candidate menu |
| Installation tie limit could be zero | An optimal status could have no retained witness | Validate a positive tie budget |
| Protocol catalogue allowed duplicate candidate identifiers | Original population provenance could be ambiguous | Require distinct original identities |
| Algebraic parameter isolation could miss a root on a domain boundary | A purported parameter cell could omit an exception | Refine exact isolations against domain endpoints and guard poles |
| Integer quotient row scales lacked original rational-map binding | A valid Smith identity could describe the wrong serialized map | Bind the original rational matrix, integer scaling and Smith replay |
| Residue seed budget was checked after initialization | A large initial population could bypass the resource ceiling | Preflight the seed population before materialization |
| An outer uncertainty enclosure used an impossibility status | Overlapping outer sets need not imply physical overlap | Report enclosure-limited certification status; bind the exact-set flag |
| A valid evaluator receipt could be paired with an altered reading radius | The optimizer could trust a bound its receipt did not certify | Replay source-bound evaluator options at optimizer entry |
| Policy/refinement replayers did not bind every status and semantic header | A valid tree could carry a false claim or uncertainty interpretation | Check schemas, statuses, semantics, fidelity direction and impossibility premises |
| Duplicate history action labels had different costs | Producer and verifier could resolve the same label differently | Require unique action identifiers |
| A supplied geometric loop matrix could be singular | An arbitrary transition could be mislabeled monodromy | Reject noninvertible loop operators |

The remaining targeted checks include direct flux evolution rather than the
sparse transition method, direct integer fibres rather than the Smith solver,
literal interval/polytope oracles rather than the production optimizer,
explicit polynomial solutions rather than differential closure, and exact
public-data normal equations rather than the empirical floating regression.

The review also checked the analytic span derivative majorant, fixed-block
all-horizon tail argument, finite decision checker independence, and the
scope of original-mask reconstruction. A narrow formal theorem does not
verify the Python parser, physical calibration or external interval engine.

Machine timings remain descriptive. The public archive excludes restricted
athlete rows; its empirical replay verifies frozen aggregates and provenance
while the structural movement results have independent exact oracles.
