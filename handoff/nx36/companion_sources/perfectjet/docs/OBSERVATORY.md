# PerfectJet Exact Observatory

PerfectJet Exact Observatory turns a mathematical system into something one can question, compress, navigate and interrogate. Supply states, actions, observations, a target and an acceptance condition. The same executable model then answers several connected questions: which states have identical futures, how many constrained histories exist, which history occupies a chosen rank, what the accepted population does at a remote length, and which experiment reveals a hidden target at the least worst-case cost. Its central design principle is **to preserve exactly the information needed by the question**. Changing the question can change the appropriate representation dramatically. This release implements that principle through a functioning local workbench, reusable Python classes, a JSON batch interface, independent benchmark calculations and an arithmetic bridge from an unbounded Pell orbit.

The main arithmetic laboratory has 2,197 original states. Its complete label-preserving behavioral model has 85 states. Exact numeric sensor evolution needs 57 linear coordinates; ordered acceptance readouts need 15; counting histories by length needs an eight-dimensional global Krylov space; the designated starting state's scalar count has a minimal recurrence of order seven. These are different mathematical objects with different preservation promises. The sequence 2,197 → 85 → 57 → 15 → 8 → 7 expresses how the information demand determines the computational burden. It does not assert that seven states reproduce the entire original machine. The workbench makes the transitions, quotient fibers, histories, experiment policies and calculation records inspectable together.

Python 3.10 or later is sufficient for this release's core. From the repository directory, install the package and launch the local interface with the following commands. The first command installs the local source; the second starts a server on the computer's loopback interface and opens its browser page. The alternate installed command is `perfectjet observatory --open`. The page provides generated mathematical examples, a model editor and JSON import, exact population controls, rank navigation, uniform sampling, an animated route, experiment design, remote coefficient queries and downloadable records. Its moving graph shows the computed finite model and selected history; it is a view of actual model transitions.

```bash
python -m pip install -e .
python -m perfectjet.observatory.workbench --open
```

An extracted release also runs without package installation: execute `python run_observatory.py` from its directory, or double-click `Start_Observatory.bat` on Windows. These launchers use the included source and open the same local workbench. Python 3.10 or later must already be available. The server prints its local address, and Ctrl+C stops it.

The source of truth is the Python implementation. `src/perfectjet/observatory/model.py` validates models and compiles their behavioral quotients; `histories.py` handles constrained populations; `series.py` constructs action-closed observable spaces and exact recurrences; `experiments.py` solves pair and adaptive interrogation problems; `arithmetic.py` transports seeded Pell orbits into finite residue systems. `examples.py` generates the example specifications. `workbench.py` presents those computations through HTTP, and `command.py` exposes the same request router for batch use. A JSON request containing `operation` and `model`, with the operation's parameters, can be evaluated using `python -m perfectjet.observatory.command request.json --output answer.json`. Exporting a model and a calculation record from the page supplies concrete material for reproduction.

The underlying finite model consists of a nonempty state set S, a finite ordered action alphabet, positive integer action costs, a partial deterministic transition Fₐ for each action, a sensor label, a target label and a terminal acceptance flag at each state. Labels are finite JSON scalars, with Boolean and integer identities kept distinct. Undefined transitions are explicit. A history is an action word, so two different actions remain different choices even when they reach the same state. This distinction is essential for exact populations: replacing two parallel labeled actions with one unlabeled edge would change the answer. Costs belong to actions and accumulate along the word. Sensor-trace constraints can include the initial reading as well as every subsequent reading.

Behavioral compilation begins by separating states with different sensor, target or acceptance labels, or different action definedness. It then splits blocks whenever an action sends their members into different existing blocks. The implementation uses inverse transition lists and a splitter worklist, avoiding a preliminary all-pairs search for distinguishing words. At termination, the quotient map π satisfies π(Fₐ(s)) = F̄ₐ(π(s)) whenever the transition exists, and preserves undefinedness and all retained labels. This equation is checked for every original state and action by `replay_compilation`. Starting from equal quotient states and applying induction on word length proves equal definedness and equal retained outputs after every finite action word. Thus every quotient history corresponds to the same labeled action word in the original coordinates.

The converse supplies minimality for these retained labels. An initial separation already has an immediate label or definedness witness. Every later separation has an action leading to a previously separated pair of blocks. Prepending that action to the previous witness gives a finite distinguishing word. Therefore two states remain together exactly when no finite word distinguishes their specified future behavior. The quotient is a minimal deterministic representation under that equivalence, including unreachable states unless the supplied model itself omits them. Preserving current target labels throughout this quotient is a stronger requirement than merely preserving terminal acceptance. The adaptive experiment solver has its own target semantics: it explicitly remembers the target of the initial hidden state even after destructive actions.

The interferometer example uses arithmetic modulo 13. Absolute states are triples (x,y,z), with relative coordinates u=x−z and v=y−z. The sensor is q=u²+v² modulo 13, represented by its integer residue from zero to twelve. Action A maps (u,v) to (u+v,v), and B maps it to (u,v+u). A transition whose next sensor is zero is blocked. Every terminal state is marked accepting; consequently the safety restriction is enforced by transition definedness. The designated initial state is (1,0,0), whose sensor is one. Counts from this safe start require every subsequent reading to remain nonzero. This convention does not declare arbitrary zero-sensor starting states safe, and it explains why global representations can retain modes absent from the designated start.

Adding the same phase to x, y and z leaves u and v unchanged. Simultaneously negating u and v leaves the sensor and all future sensors unchanged because both shear maps respect that sign symmetry. There are 169 relative states and (169+1)/2 = 85 sign orbits. The benchmark checks the complete computed partition against this independently derived translation-and-sign relation, rather than checking only its size. The fiber over the relative zero orbit has thirteen absolute states; each other fiber has twenty-six. From the designated safe start, only 72 relative states and 36 quotient states are reachable. The 85-state quotient and the global linear dimensions refer to the complete supplied model, so they should not be confused with those reachable-state counts.

Action order remains visible after symmetry reduction. Starting at (u,v)=(1,0), applying A then B ends at (1,1) and gives q=2. Applying B then A ends at (2,1) and gives q=5. Both words contain one A and one B. Their action histograms agree while their outputs differ. This concrete witness shows why a commutative inventory of actions cannot replace the ordered model. Pair experiments can also separate two states that currently have the same sensor when their future readings diverge, while antipodal relative states remain indistinguishable under every finite word. The workbench's orbit picture therefore represents a dynamical equivalence, rather than a visual grouping by current color.

For an exact horizon h, remaining budget b and starting state s, let C(h,s,b) be the number of accepted continuations satisfying the requested sensor trace. A mismatched current trace entry contributes zero. At h=0 the value is the terminal acceptance flag. Otherwise, C is the sum of C(h−1,Fₐ(s),b−cost(a)) over defined, affordable actions. The unconstrained-budget version omits b. The recurrence is exact because every nonempty word has one first action and a unique suffix, and the first-action subsets are disjoint. Equal target states do not merge those subsets. Memoization shares repeated continuation questions, while an explicit evaluation stack avoids recursion-depth dependence. Sufficiently generous budgets are removed as redundant coordinates.

Ranking refines the same decomposition. In the original action order, all histories beginning with the first action occupy one interval of size equal to that action's continuation count; the next action occupies the following interval, and so on. To rank a valid word, sum the intervals belonging to earlier first actions and recursively rank its suffix. To invert a rank, find its containing interval, subtract the interval's starting position and continue. Induction on h proves that these procedures are inverse bijections between accepted words and the integers from zero through C−1. Uniform sampling therefore needs only a uniform integer in that interval followed by inverse ranking: every accepted word has exactly one preimage and probability 1/C. This avoids sampling unconstrained words and rejecting nearly all of them when valid histories are rare.

Linear observable compression asks a more specific question than behavioral equivalence. Regard an observable f as a function on all quotient states. Define its action pullback by (Tₐf)(s)=f(Fₐ(s)), assigning zero at an undefined transition. Starting with acceptance and any explicitly supplied numeric observations, the compiler repeatedly adds action pullbacks that are linearly independent over the rational numbers. Finite dimension guarantees termination. Its basis matrix C and reduced action matrices Bₐ satisfy C[:,Fₐ(s)] = BₐC[:,s], with the zero vector for an undefined transition. Exact reconstruction of every retained seed observable and induction over ordered words prove preservation of every requested future readout. Basis-source words are recorded, so each basis function can also be replayed directly from its originating observable.

For the interferometer, including numeric q and acceptance produces dimension 57; including acceptance alone produces dimension 15. These are exact rational dimensions of functions on the finite state set, not numerical ranks from singular-value thresholds and not ranks over the field of thirteen elements. The 57-coordinate representation recovers the integer residue reading q after every ordered word. The 15-coordinate representation recovers the accepted-word readout but makes no promise to reconstruct q. Because acceptance is one at every live state in this example, its pullbacks also reveal whether a word remains defined. The benchmark replays 6,120 basis-source evaluations across these two closures and checks every reduced operator identity. Choosing an observable is consequently a precise specification of which information may be discarded.

Length counting discards another distinction: it sums over every action word of the same length. Write A=ΣₐTₐ and let f be the acceptance indicator. Then vₖ=Aᵏf is a whole-state vector whose entry at s counts accepted words of length k from s. Incremental exact elimination finds the first dependence vᵣ=Σⱼcⱼvⱼ. All earlier vectors are independent, making r the global Krylov dimension. Multiplying the identity by Aᵐ proves the recurrence for every subsequent length and every starting state. `compile_series` checks this vector identity explicitly; it does not infer an all-time law merely because a fitted recurrence matches a finite prefix. The recorded residual has one coordinate per state and is identically zero.

In the interferometer, r=8 and the lag coefficients are (1,0,0,2,−2,0,8,0). Thus the global recurrence is aₙ=aₙ₋₁+2aₙ₋₄−2aₙ₋₅+8aₙ₋₇ for n≥8, with its formally retained eighth lag equal to zero. For the designated start, the first values are 1,2,4,6,10,14,22,34, and the generating function is P(z)/Q(z), where

\[
P(z)=1+z+2z^2+2z^3+2z^4+2z^5+4z^6,
\qquad
Q(z)=1-z-2z^4+2z^5-8z^7.
\]

Eight describes the whole-state vector space; seven describes this selected scalar sequence. The global characteristic relation has a zero mode whose contribution vanishes at the designated safe start. Here the scalar recurrence already works from n=7. The benchmark independently computes the polynomial greatest common divisor of P and Q and obtains one; because the rational function is proper and reduced, its scalar denominator degree seven is minimal. The general library reports its global recurrence and explicitly avoids claiming that it has minimized every selected scalar output. This distinction matters whenever unreachable or unobserved modes disappear upon evaluation at a particular state.

Remote queries use the characteristic relation as a polynomial reduction rule. Reduce xᴺ modulo xʳ−Σⱼcⱼxʲ by binary powering; if the remainder is Σⱼdⱼxʲ, the same relation gives \(a_N=\sum_jd_ja_j\). There are O(r² log N) arithmetic operations with ordinary polynomial multiplication. Applying every operation modulo M keeps intermediate integers bounded by that modulus, including when M is composite. At length 10¹⁰⁰, the interferometer count modulo 1,000,000,007 is **976,449,876**. An independent modular matrix-power calculation on separately derived reachable sign orbits agrees. An exact unmodulated answer can require an enormous number of bits; jumping over earlier indices cannot remove the cost of representing the answer itself.

Experiment design introduces a different kind of compression: uncertainty about the current hidden state. A belief stores pairs (initial state,current state), retaining the initial target label through every transition. An undefined transition moves its hypothesis to an absorbing undefined observation; it does not silently remove that possibility. Free sensor readings partition the belief into observation branches. A branch is identified when every remaining initial hypothesis has the same target. The solver minimizes worst-case accumulated positive action cost. For a nonterminal belief B its Bellman equation is V(B)=minₐ[cost(a)+maxₒV(Bₐ,ₒ)], with identified beliefs assigned zero. This is a guaranteed identification objective; no prior probability or average-case information score is substituted for it.

The adaptive algorithm builds the reachable belief graph, then runs a reverse AND/OR form of Dijkstra's algorithm. An action offers a finite candidate only after all its distinct observation-successor beliefs have finalized values. Its candidate is its cost plus their maximum. A priority queue finalizes the smallest available candidate. To prove exactness, suppose the first incorrect finalization were more expensive than an optimal finite policy. Positive action costs make every child of that optimal first action strictly cheaper than its parent. Those children would already have finalized correctly, so the optimal candidate would already be in the queue, a contradiction. Chosen policy edges strictly decrease V, yielding a finite shared decision DAG. If complete exploration leaves an unresolved region, every action has an observation successor still inside it; this closed ambiguity region witnesses the absence of a finite guaranteed policy.

The branching laboratory demonstrates a strict adaptive advantage. An unknown device belongs to family alpha or beta and holds a hidden bit. Routing first reveals the family; inspecting that family then reveals the bit. The exact worst-case cost is two. Choosing the wrong family's inspection makes the relevant hypotheses undefined without revealing their bit, and both retain their original targets. An independent complete search through eight preset-word monitors, including their full observation histories, finds no fixed action word that identifies the bit in all cases. A separate irreversible-button example assigns cost three to inspection and cost one to reset. Reset merges both initial bit possibilities into the same current state, permanently destroying their distinguishability. The optimal separating experiment is inspection, showing that cheap motion and useful information are different quantities.

The solver can also condition on a fixed action prefix while preserving its entire recorded sensor history. Calling `adaptive_experiment` with `belief=[0,1]` and `prefix=["reset"]` on the hidden-bit example makes guaranteed identification impossible. With `prefix=["inspect"]`, the remaining optimal cost is zero because the bit has already been learned, and total cost is three. With `prefix=["inspect", "reset"]`, remaining cost is still zero and total cost is four: erasing the device after observing its bit does not erase the observer's information. Beliefs with identical current states remain separated by their earlier observations when those observations already identify their different initial targets. Prefixes are capped at 512 actions, and the returned total cost includes that already executed prefix as well as the optimized remaining experiment.

The arithmetic bridge extends the same architecture to a genuinely unbounded original object. `pell_residue_system(D, unit, seed, modulus, accepted_x=...)` takes a supplied norm-one unit a+b√D and a seed on x²−Dy²=N. Multiplication uses the matrix [[a,Db],[b,a]], whose determinant is one and whose inverse replaces b with −b. Direct expansion proves preservation of x²−Dy²; its characteristic polynomial gives zₙ₊₂=2azₙ₊₁−zₙ for each coordinate. Reduction modulo an integer m produces an invertible finite action, so the seed's orbit is a closed cycle without a transient, even for composite m. Advance and retreat become ordinary Observatory actions, and index n maps to cycle index n modulo its period. The record states whether the supplied generator is fundamental, while its completeness claim remains restricted to the supplied seed and generator orbit.

For D=2, unit (3,2), seed (1,0) and modulus 35, the compiled cycle has period six. Requiring terminal x≡1 selects cycle index zero. Among 100-step advance/retreat words, exactly 422,550,200,076,076,467,165,567,735,126 are accepted. An independent check sums binomial(100,k) over (2k−100)≡0 modulo six, because a word with k advances has that net exponent. `pell_point` separately reaches signed indices by binary powering; at index 10¹⁰⁰ modulo 1,000,000,007 it returns (366654601,394441112), and the norm identity replays modulo that modulus. These results concern one seeded orbit. They do not establish that the seed covers all integer solutions of the norm equation; that additional arithmetic completeness problem must be handled separately.

Reproduce the retained computations with `python scripts/benchmark_observatory.py --horizon 80`, and run the Observatory suite with `python -m unittest discover -s tests -p "test_observatory*.py"`. The machine-readable interferometer record is `results/observatory/benchmark.json`. Independent comparisons include forward propagation in absolute, relative and sign coordinates, complete enumeration of all 8,191 binary words through length twelve for the modulus-five example, rank/inverse-rank round trips, basis-word replays, scalar polynomial gcd and remote matrix powering. Unit tests also compare random finite systems against direct enumeration, exercise repeated-root and nilpotent recurrences, check zero outputs and empty alphabets, and compare adaptive decisions with exhaustive small games. Timing fields describe the recorded workloads on their execution environment; they are not universal speedup claims.

The Pell and destructive-prefix records are saved separately as `results/observatory/pell.json` and `results/observatory/destructive-prefix.json`. After installing the package, the following Python snippet recreates both directly from their public APIs. It preserves the distinction between the initial unexecuted plan, resetting before learning and inspecting before any further action. The inspect-then-reset case is additionally covered by the experiment tests.

```python
import json
from pathlib import Path
from perfectjet.observatory.arithmetic import arithmetic_receipt
from perfectjet.observatory.examples import irreversible_machine
from perfectjet.observatory.experiments import adaptive_experiment

destination = Path("results/observatory")
destination.mkdir(parents=True, exist_ok=True)
(destination / "pell.json").write_text(
    json.dumps(arithmetic_receipt(), indent=2) + "\n", encoding="utf-8")
prefixes = {"none": [], "reset": ["reset"], "inspect": ["inspect"]}
records = {name: adaptive_experiment(irreversible_machine(), belief=[0, 1], prefix=word)
           for name, word in prefixes.items()}
(destination / "destructive-prefix.json").write_text(
    json.dumps(records, indent=2) + "\n", encoding="utf-8")
```

The implemented resource boundaries are explicit. The workbench accepts at most 10,000 input states and sixteen actions. History queries allow horizons through 512 and at most one million dynamic states. Exact rational closure defaults to at most 128 quotient states. Adaptive exploration defaults to 4,096 beliefs and reports `limit`, with solvability unresolved, when it cannot finish within that allowance. Pell residue compilation defaults to at most 100,000 orbit states; unmodulated Pell coordinates have a one-million-bit allocation guard. Backend functions expose relevant limits where supported. The workbench asks for a modulus beyond length 10,000 to avoid enormous exact outputs. This release adds computational identities, proofs of the algorithms given here and replayable evidence; it adds no new Lean proof of these executions. It is a finite deterministic tool, with a seeded arithmetic adapter, rather than a general solver for arbitrary mathematics or noisy stochastic dynamics.

The next expansion should preserve this architecture while increasing the classes of admissible models. Existing `engine.adaptive_closure` and `polynomial.feature_closure` already describe polynomial dynamics through exact feature identities. A polynomial adapter should submit the user's requested outputs, generate a finite closed feature representation when one is found, and return the residual monomials when its degree or feature budget prevents closure. Existing `lattice.integer_solve`, `smith_form`, `hermite_form` and `saturation` can supply integral feasibility and transport checks, so rational coordinates do not get mistaken for realizable integer states. Existing `quadratic.QuadraticSquare` can contribute arithmetic solution populations beyond the seeded Pell demonstration, with modular filters accompanied by their precise lifting obligations. `parametric.rank_cells` can expose parameter regions where observability changes, and `readout.identify` can produce exact hidden-direction witnesses and sensor-repair questions.

A concrete next stage is therefore an adapter contract carrying the original model, the question, the compiled representation, its transport map, the retained readouts, identities, limits and unresolved obligations. `engine.report` already provides a related reporting vocabulary. The workbench can then offer a user's next mathematically justified action: refine a sensor, change an experiment after a reading, inspect an arithmetic obstruction, or evaluate a remotely indexed count. Those additional adapters require implementation and domain-specific completeness arguments; they are a development plan rather than a delivered universal interface. The current release supplies the shared executable nucleus: ordered dynamics, demand-specific compression, enormous exact populations, arithmetic transport and experiments that act on what their observations reveal.
