# Observatory 0.15.0 validation

The complete repository test run passed 431 tests in 53.531 seconds on the retained environment. The Observatory-focused suite passed 54 tests. After the final request-boundary corrections, the four HTTP/workbench integration tests were rerun and passed. Tests compare independent algorithms and explicitly exercise partial actions, typed observations, original target memory, destructive prefixes, huge integer populations, nonfundamental Pell generators, and finite resource limits.

The compiler was compared with the older pair-distinguishing implementation on ninety random finite systems. History populations were compared with exhaustive action-word enumeration on 150 randomized constrained queries. The compiler also handles a 1,500-state chain whose only distinguishing sensor lies at its terminal end and a 1,200-state redundant periodic system. A single-state binary model counts 2^512 histories with 513 dynamic cells. Rank and inverse rank are checked in original action coordinates, including multiple actions with identical state transitions.

Experiment planning includes all 648 retained two-state partial-system/sensor/cost combinations, 120 independently solved three-state budget games, and 120 independently solved prefix-conditioned games. Impossible policies supply a closed region containing a losing successor for every possible action. A resource limit reports unresolved solvability. Prefix tests preserve observations made before a later state merge, so an erasing transition cannot incorrectly make already learned information disappear.

The arithmetic benchmark independently derives absolute phase, relative phase and simultaneous-sign dynamics, then compares their populations through length 80. It enumerates all 8,191 binary words through length twelve for the smaller prime-five system. It compares the quotient fibers with the explicit translation-and-sign relation. Exact global vector identities establish the recorded recurrence; an independent modular matrix-power implementation on formula-derived reachable sign classes reproduces the coefficient at index 10^100. Numeric-sensor and acceptance operator bases, their readout maps and the scalar polynomial gcd are retained in the receipt. These calculations establish the stated finite example; timings characterize only that workload.

The separate Pell receipt checks direct integer iteration through index fifty, exact norm preservation, the finite residue cycle and its inverse, and the binomial-fiber count of accepted advance/retreat histories. It records the supplied seed and unit, distinguishes a fundamental unit from a proper power, and limits completeness to the generated seed orbit. It does not establish all integer solutions of an arbitrary norm equation.

The interface has real loopback HTTP tests for token handling, JSON errors, original-to-quotient transport, action names containing spaces, adaptive prefixes, exact-output digit limits, remote counts, numeric sensor closure and original Pell coordinates. `scripts/check_observatory_ui.js` executes the actual shipped JavaScript against the real Python HTTP adapter using a minimal DOM contract. It verifies model switching, default action names, clearing stale custom-model constraints, rank navigation, uniform draws, recurrence queries, both observable demands, policy branches, prefix destruction, the Pell bridge, and canvas control flow. It passes without third-party Node packages. This is an interface logic check, not visual rendering validation.

Interactive browser rendering was not verified in this environment. The available cloud browser cannot access the isolated loopback server, and a local Chromium binary was unavailable. The interface therefore carries no claim of a completed visual browser pass. Its HTML/JavaScript syntax, real backend contracts and UI control logic were checked. The wheel builder includes `perfectjet/observatory/assets/index.html`, and the extracted-source launchers require only Python 3.10 or later.

The equation/topic builders and source-hash coverage checks pass with thirty canonical chapters, 417 equations and 506 topics. The complete release ZIP is rebuilt from the retained source and checked against its generated SHA256 manifest. No new Lean proof is claimed. The monograph supplies the mathematical algorithm arguments while the tests and receipts supply computational execution evidence.
